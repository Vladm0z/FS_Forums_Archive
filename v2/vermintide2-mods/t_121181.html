I’m working on creating a dynamic portrait that changes depending on your hat, or in cases where the hat must match the outfit, then it’s determined by the outfit instead. I find myself looking at other players’ framed portraits a lot more than their actual models during gameplay, so this felt like a worthwhile project. So far I’m still working on Kruber. I’m going to be very busy over the coming months, but I’ve turned my modding attention to Vermintide 2 for the first time.

I’ve been working in Photoshop using screenshots of the model on the new inventory screen, since that nice white backlighting makes the portraits look really clean. So far I’ve been able to replace the portrait in the frame with these when a matching cosmetic hat is equipped, so it kinda works.

The problem I’m running into is that the image here is 110x130, but the character icons in frames are 86x108, and I haven’t been able to find them in the game files. They’re cropped to fit the frames, and mine are not.

If anyone can help me track those down, I’d really appreciate it so I don’t have to blindly crop them. For now, trial and error might have to do.
