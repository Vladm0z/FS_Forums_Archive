Console Hotfix 1 - 24th of May

Features & Tweaks

  • You no longer unlock next ranked weave if you finish a game without any time left.
  • Added new visuals for when Heroes have two or more charges of a career skill (due to Chaos Wastes Boons)

Fixes

  • Fixed crash when applying weave skins in chaos wastes hub.
  • Fixed an issue where host purchasing Miracles would override the Weekly Event curses/boons in the TAB menu.
  • Fixed bug where abilities didn’t proc Mathlann’s Storm-Strike boon.
  • Fixed a bug where Xokha’s Duty boon triggered multiple times if there were more than 1 human player in the game.
  • Fixed bug where “Guaranteed crit on heavy attacks” boon didn’t work on dual weapons
  • Fixed Be’lakor skulls not spawning on non Be’lakor nodes when mutator is active (due to weekly expedition)
  • Fixed The visual effects of the new bomb boons lasting much longer than the actual gameplay effects.
  • Fixed bug where Kerillian bows with weave skins applied don’t show any arrows.
  • (Weaves) Fixed so no bonus time is added and that you progress to the next phase even if you have no time left.
  • [PS4 Only] Fixed a crash when using one of the new team aura boons and attacking a damageable level object while a teammate is near.
  • [PS4 Only] Fixed the voting screen in Chaos Wastes having overlapping text sometimes.
  • [PS4 Only] Fixed an issue where all boons were showing a 3/3.
  • [PS4 Only] Fixed a bug in the crafting menu where all weapon types would disappear when deselecting rarity.
  • [PS4 Only] Fixed an issue where boons that were part of boon sets did not mention that in the Chest of Trials menu.
  • [PS4 Only] Fixed not being able to apply weave skins on Masterwork Pistol and Shade’s repeating crossbow.
  • [PS4 Only] Fixed a duplicated button prompt in the loadouts menu.

* Note: fixes marked as PS4 only were already in the Xbox version at patch launch.
