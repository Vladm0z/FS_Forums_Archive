Heroes!

As promised, the Feast of Grimnir event has returned! From August 25 to September 6, venture forth into Karak Dal once again to slay every troll in sight and make Cousin Okri proud!

For the duration of the event, select the Weekly Event game mode in the Adventure map to launch the Feast of Grimnir mission! Complete the mission to progress in various repeatable Event Quests found in Okri’s Book and receive shillings and chests!

Make sure to also check Lohner’s Emporium of Wonders for time-limited access to previous event rewards, purchasable for shillings!

Without further ado…

Patch 6.12.0 patch notes

Features & Tweaks

  • Feast of Grimnir
    • Updated the Troll Chief’s portrait frame to be more fitting to their chieftain status. Now boss phase information is presented similarly to grudge marks.
    • Troll Chief now uses ‘Lord’ damage reduction instead of ‘Boss’. Max health was lowered to compensate, but should overall be a tougher beastie to bring down.
    • Troll Chief health was increased by aproximately 15% in Cataclysm 3.

Fixes

  • Fixed a crash when firewall software blocks connecting to Twitch servers.
  • Fixed a crash when the Necromancer sacrificed a skeleton that had already died in the host or server.
  • Fixed a bug that allowed Necromancer to sacrifice the same skeleton multiple times with enough latency.
  • Fixed several unlocalized strings in the equipment customization view.
  • Fixed a crash that only happened on Mondays when closing the Weekly expedition view while it is refreshing. No, really.
  • Fixed a crash when interacting with a Keep painting around the time there is a seasonal keep change.
  • More fixes on the Skittergate invincibility.
  • Fixed a crash when receiving a reward from the backend while running an older game version.
  • Fixed a bug where runed illusions for Kerillian’s Longbow had lower glow intensity than intended.
