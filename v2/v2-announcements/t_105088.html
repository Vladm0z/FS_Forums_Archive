Hotfix 6.3.2 - 6th of February

Features & Tweaks

  • (Versus) Added Custom Game Settings for:
    • Toggling Hero Rescue points.
    • Setting the round time limit.
  • (Versus) Turned the Pactsworn Health settings in Custom Games into a slider. Also, redesigned how the Custom Settings sliders look.
  • Sound cooldown when pinging the same target or placing a new world marker increased from 0.5 seconds to 2 seconds.
  • Sound cooldown when pinging unique targets increased from 0.5 seconds to 0.7 seconds.

Fixes

  • Tower of Treachery - Fixed a guaranteed crash when leaving the library.
  • Fixed bots getting stuck in the tower of the third tome spot in Halescourge. For real for real this time! On Sigmar!
  • Fixed a bug where Rat Ogres weren’t properly playing footstep SFX in non-Versus game modes.
  • Fixed a crash when joining into an ongoing Weave level with already completed capture point objectives.
  • Fixed a bug where the Iron Breaker talent “Rune-Etched Shield” and the Handmaiden talent “Asrai Alacrity” were only working for the host.
  • Fixed a bug where Saltzpyre would get confused and respond with a Kruber voice line when Sienna kills a troll.
  • Fixed an issue where clicking on the pose cosmetic icon you ended up in the wrong subscreen, resulting in players being able to equip forbidden weapons.
  • Fixed a pose crash when no default pose is present in the inventory.
  • Fixed a rare crash when a player sends a message during a very specific moment during host migration.
  • Fixed an issue where recently purchased weapon poses wouldn’t show up right after purchasing them.
  • Devious Delvings bug fixes:
    • Fixed the ‘No Time like the Present’ Okri’s Challenge not completing on clients.
    • Fixed an overzealous hang ledge next to a ladder.
    • Fixed a bug where healthbars for objectives sometimes didn’t show properly.
    • Fixed bug a where the boss fight never ended if the Twins modifier was active.
    • Fixed the Recruit and Veteran versions of the Okri’s Challenges having swapped icons.
  • Versus bug fixes:
    • Fixed a bug where enemy Heroes would use the same portrait frame as your bot loadouts, instead of their own.
    • Fixed a bug in custom games where a leap animation was played on all Rat Ogres if one of them performed a leap attack. No more auto-synchronized dances, you’ll have to time those yourselves!
    • Fixed a bug where two Packmasters could hook the same target, leading to one of the Packmasters becoming stuck in place.
    • Fixed a bug where Rat Ogre gets stuck in leap animation if using the leap ability while inspecting the character (with X)
    • Fixed a bug where Heroes could be unkillable on certain values for the Hero Damage Amount setting.
    • Fixed a bug where players in a Versus Custom Game character selection were not able to pick the character that the host and their party members played as in the versus keep before the match.
    • Fixed a controller input bug for Versus Custom Game settings where the slider would not go all the way to the bottom when selecting the first option.
