munis • 2020-02-20 20:37:51

Versus seems to be the future and it looks like much is happening under the hood that maybe at least partially goes under the category of redoing the game from inside out. Except for bugs those changes are not visible to the player for now at least. My personal opinion is that many of the recent issues have arisen from Versus development - we are beta testing some of the new and changed mechanics which I guess is a good thing given how it seems real betas are just early access with no chance to affect the version going live kind of a deal.

Given how the assets are bundled so that each level has it’s own copy of everything (tens of gigabytes of duplicates as show by IamLupo) and assuming that bundling style is here to stay, it would be very easy to make Versus a standalone.

Also that means it could be a integrated part of the base game. I hope it will be, and hope it will be very much integrated into regular gameplay just for having fun and then a separate game mode for the competitive side of it. Fun mode for me would be getting to control some enemies if you are dead and also a spectator mode from which you could join if a slot frees up. The fun mode is slightly problematic in the sense that it would allow deliberate sabotage of the pact sworn side and that generally seems to be something the game designer doesn’t like (any little thing that makes the odds more in players favor are fixed).

As it is quite obvious there is no longer much work done for the base game (adventure game mode), I hope the Versus team will see things from another (fun) perspective and drive some good decisions through.

I still see dedicated servers being a possibility given how the game internals are getting changed into a direction where it could actually work (also direct work on dedicated server support seems to be happening, not.just vague hints of it). How that would make any difference except for Versus rage-quit prevention I don’t know, but people seem to still want to run a server regardless.

Performance (both in terms of frametime and network) has been going in a steep spiral down for as long as I’ve been playing, but the Versus team must know that a PvP game cannot be this bad and thus I see hope for that getting a serious look at some point.
