Tamren • 2022-11-19 15:33:47

This topic comes up every few months yet nothing is ever done about it. A pure RNG based system is just garbage, the problem isn’t that it will take 1000 more hours for me to unlock everything. The problem is that I could potentially spend 1000 hours and STILL not get everything, there is no guarantee that the effort you spend will amount to anything. Getting multiple duplicates of the same thing just adds to the frustration, I once got the same repeating crossbow four times in a row. There are so many ways you could fix this problem.

For instance, they could simply disable duplicates outright. If that’s too easy, then make it more likely for players to get red items they don’t already have. This allows players to make constant forward progress, every item you unlock increases the chance of unlocking a new item. Eventually the players would have at least one of every item and the system could then revert back to 100% RNG.

In addition to the above I would hard code the drop system so that it cannot drop the same item twice in a row, or even twice in the same chest.

Another thing they could do is give players a “last resort” option that they can fall back on if everything else fails. Put red illusion skins into lohners emporium where the purple skins already are. If you want them to be exclusive then all you have to do is make them expensive, price each skin at 2000 coins, or even more than that! It doesn’t matter what the price is, only that this option exists at all. It means that your grind is finite and you are guaranteed to get at least one thing that you want for a given amount of effort.

Another version of the “last resort” option could be crafting using red dust. Lets say you could pile 25 red dust together and craft it into a random weapon illusion you don’t yet own. This would instantly flip how players feel about the RNG grind on it’s head. It no longer matters as much if you get a duplicate item because EVERY red drop is a good red drop that represents forward progress.

In summary, this system has been a source of nothing but frustration for basically the entire playerbase since the game launched. It would be so easy to solve if fatshark were willing to do anything about it.
