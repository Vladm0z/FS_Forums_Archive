End Game content update proposal

This topic aims to present a major area of improvement for the game’s end-game content.
It’s clear that recent updates haven’t added meaningful content for veteran players who are still looking for tougher challenges.

Definition of end-game:

By “end-game,” I mean anything harder than a standard Cataclysm run — things like deeds, Twitch mode, weaves, events, and weeklies.

  1. Deed System Rework

The current deed system feels frustrating due to the lack of control over modifiers.

A fully customizable system would be far more valuable.
Also, deeds must be joinable via the lobby browser. Right now, we have to use a bug exploit just to join a friend playing Deeds…

Concept:

  • The player can select to add a deed to both campaign AND chaos waste. Then he choose any modifier he wants to add to his deed.

  • Modifiers can be selected from a lootable pool (earned through chests). Reward is based on the amount of modifiers.

  • Players then pick any map and difficulty to play on.

Important change:
Deeds and modifiers are no longer consumed, regardless of whether the run is a win or a loss.

New Modifiers:
There are already tons of unused modifiers in the game (from Weaves, Chaos Wastes, weekly events, etc.) that could be added to deeds.

Also, Cata2 and Cata3 should be available as deed modifiers.
(Note: These difficulties already exist in Weaves and are widely played in the modded realm.)

If selected, these modifiers would override the chosen difficulty. For example, a deed with Cata3 launched on Recruit would still run as Cata3.

  1. Twitch Mode Improvements

The current Twitch system is good, but it limits player control. A more advanced customization system would greatly enhance the experience.

Suggested changes:

  • Add a “no duplicate” option to prevent the same event (e.g. monster spawn) from happening back-to-back — especially useful on 200% or 300% Twitch settings.

  • Allow players to tweak vote timer, event interval, and chat command percentage mid-game via commands like:
    /interval:30 or /percent:199

  • Add new Twitch events from other game modes (like with the deed system).

  • Include a setting to manage enemy health bonus %, scaling similar to Cata2 and Cata3.

  • Include a setting to manage enemy stagger resistance bonus (yes i like deathwish).

Let me know if you also would like some changes in Deeds & Twitch in the comments
