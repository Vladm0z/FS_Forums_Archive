Saving character builds and bot party selection

8 Posts • 2460 Views

Slayerkin • 2019-05-01 16:07:42

There are two features I would like to see in a future Vermintide 2 update; ability to save character builds and custom bot character selection, which ties into each other in a way. Both of these are intended to save time for the players.

The first idea is that if you’ve got a build for a character; say a Zealot with a specific set of gear and selection of talents and cosmetics, then you can save this so that if you want to play a Bounty Hunter for a while you wouldn’t need to go back and manually create the Zealot build again. You just go to career options and select that Zealot build and you’re ready to go. And that all gear assigned to a build is marked in the inventory so that in haste you don’t salvage some important item that you didn’t think about was part of a build.

The second idea comes from the fact of life that the friends that you play with may have work, family and other commitments that don’t let their schedule line up perfectly with your schedule all the time for everyone. And thus it would, in my opinion, be a great and good thing to let us select what builds (see above) we want the bots to be in our party, as well as when playing with both bots and humans so that we can be certain to get a specific bot we want at a certain time. For example I would love to see more of Sienna as a bot in my games but she never shows up unless a player picks her.

I’m not entirely sure if you have checked out the bot priority list (I don’t know if it exists for consoles) but you are able to select the priority table for which bots appear in your games, rated from 1-5.
