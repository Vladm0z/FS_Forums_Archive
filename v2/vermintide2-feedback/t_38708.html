I’ve already made a suggestion for a survival mode in Vermintide 2 multiple times. Hopefully we can have a Map Editor to help augment it should the developers decide to make something like this.

Survival Mode:

Have interconnected zones that represent different environments which the heroes can move back and forth from as they defend waves of randomly spawned enemies (not set spawns like Fortunes of War). Environments: Village/City (mixed enemies), Chaos Encampment (more norsca spawns), Forest Road (Beastmen/Mix), Skaven Outpost (underground / skaven spawns) and then perhaps roads / pathways to connect each area.

Lohner and Olyshea, using smuggling / magic, will occasionally resupply the heroes after a few waves. These supplies will spawn in different zones each time which should encourage the heroes to move around defending from different spots. Ammo boxes wouldn’t spawn but the occasional explosive barrel will.

As stated spawn would be completely random based on difficulty and would obviously scale with each wave. For possible rewards I could see portraits and a few cosmetics given when you reach certain waves on difficulties. Otherwise Chests wouldn’t really be the focus as it’s more of a last as long as you can sort of idea. If Chests were a reward you’d need random tome/grim spawn locations and a portal that opens at a set wave number and then remains up until the heroes choose to try and leave - probably make the portal in it’s own location or in the village/city and preferably in a spot that isn’t so easily defended.
