This is a small QoL change:
It’s time to finally make order between weapon icons. Loads of icons are missing, wrong placed and misrepresent an actual skin applied etc. Moreover, some icons are difficult to read due to it’s simillarity.

So these are my propositions:

  1. Rework icons that can be mistaken to icons of other weapons


it’s not hard when you put some thought in it. Make icon types readable easily. This is a question of accessibility as well. Some players with certain disabilities may have hard time reading icons that are too similar to each other in shapes.

  1. Rework Red (glowing) illusions icons so they represent actual look. It would help to distinguish between normal and glowing icons and also help with distinguishing between purple and blue glow.

    20190918185407_1643×525 79.4 KB

    Note that, again, blue and purple icons must be different.
    Since you’ve already made a lazy work (harsh, I know, but it is questionable by many if it’s not true) with illusions running with just recolorations of already existing assets, you might as well put some effort in separating them for players for easy access.

  2. Review all the icons so they represent the related weapon skins properly. Some skins are missing illusions btw and replaced with wrong icons (check up Bardin’s melee arsenal for example)
