I appreciate the issue with these cosmetics has been around for a long while

  • Banishing Blade
  • Pegasus Bulwark
  • The Doom of Anmyr

The cosmetics were shown incorrectly in the UI after we updated it, but were not obtainable. This has been held up by a decision needing to be made on whether we removed them from the UI or released the cosmetics in some way. However, due to other priorities this has taken a backseat repeatedly. I’ve given this issue another nudge though and I’ll try making some noise internally again!

Regarding the ‘Abasement’ portrait frame, this was awarded to all player accounts affected by a severe data loss issue that occurred on Versus release. Our backend developers identified all accounts with this issue and over the course of a few months manually rebuilt and restored the missing data to these accounts. You can find more info in the thread we used to track this issue, here:

KNOWN ISSUE: Account Data/Progression Loss for Some AccountsTechnical Support

We’re working to resolve this as swiftly as possible. Please bear with us!
