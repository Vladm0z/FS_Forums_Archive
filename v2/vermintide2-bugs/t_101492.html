Issue Type (Required):

Player Mechanics

Issue Description (Required):

In versus tags are considered as a socialwheel interaction. This triggers the socialwheel cooldown. However, I believe due to the same line of code for tagging being used with vanilla and versus, tagging enemies a lot in vanilla also triggers this cooldown. If you’re spam tagging enemies in vanilla (as you should) it often prevents you from using the socialwheel, at least way less often than you normally can. It has hindered me in the past and been a problem since the tests begun, I was lazy to report it.

A small request is to seperate the versus mark tag with vanilla blue outline tags. As I find it a hinderance when swapping from vanilla to versus because I have my tag only bound on LMB and it can cause disturbance when marking elites or items in versus as well. Since any WHC player (or anyone in general) should or could lean towards tag spamming for efficiency. It’s annoying to have a mark appear every time it’s not on point and disturb my usage of the socialwheel because it adds up to the cooldown.

Steps to Reproduce (Required):

  1. To really notice the bug, check how many social commands you can spam back to back beforehand, then wait a minute for the cooldown to end.

  2. Get in game with any class and stand in front of any tagable object.

  3. Start spam tagging it for 5-6 times or more for good measure.

  4. Try spamming socialwheel to see the difference.
