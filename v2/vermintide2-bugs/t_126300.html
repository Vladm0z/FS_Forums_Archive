Issue Type (Required):

Weapons

Issue Description (Required):

Some polearm weapons cause a very slight angle rotation to the view. This off angle persists as the default view while the weapon is out, but swinging and blocking will temporarily reset the view to the base view angle. So either every other weapon has the default view angle wrong, or these three weapons have something wrong.

This affects:

  • Kruber’s Halberd
  • Kruber’s Tuskgor Spear
  • Saltzpyre’s Bill Hook

EDIT 1: Just noticed this was reported in 2022 (Camera tilt on certain weapons).

Steps to Reproduce (Required):

  1. Swap to any of the three affected weapons (Kruber Halberd, Tuskgor Spear, Saltzpyre Bill Hook).
  2. The view angle will now have the slight rotation (while in the default holding weapon stance).
  3. The view angle rotation can be most easily observed by blocking repeatedly or swapping weapons quickly, showing the visual change.

[PC] Do You Use Mods? (Optional):

Yes, but I haven’t tried disabling them

Reproduction Rate (Required):

Constant (100%)
