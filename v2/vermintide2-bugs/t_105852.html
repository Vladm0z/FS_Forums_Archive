Issue Type (Required):

Launcher

Issue Description (Required):

Overlays like the Steam Overlay (I’ve also heard of RTSS or MSI Afterburner causing the same issues, though I don’t use those services myself) seem to cause frequent visual glitches in the mod selection window in the launcher. Seen in the attached images is the FPS count of the Steam Overlay, which is usually only seen as a small number in the corner of the screen while playing the game. Here they’re frozen and stretched out over almost the entire window. Scrolling around or simply moving the mouse over the mods sometimes makes them partially disappear, sometimes come back, just generally do weird stuff basically.

It’s a purely visual glitch, it doesn’t actually affect anything past that.

I should also note that this has been happening for years and just mentioning it in a Discord Server brought up many others who have also been affected by this for a long time. The main reason I’m reporting it now is so I can differentiate this bug from another one I’ll report after, in which I can then simply link this report as well.

Steps to Reproduce (Required):

  1. (presumably) Have an Overlay activated
  2. Start up the Launcher
  3. Open the mod selection screen of the Launcher
  4. Scroll around or check/unckeck some mods or have anything happen that would be shown on the Overlay (like friends starting up a game in case of the Steam Overlay)

Reproduction Rate (Required):

Constant (100%)

Platform (Required):

PC - Steam
