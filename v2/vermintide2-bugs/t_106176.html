Issue Description (Required):

Description of Sigmar’s Executioner gives false informations in german translation (Sigmars Henker).
English text: Killing an Elite enemy grants 5% critical Strike chance for 12 seconds. Max stacks 3.
German text: Das Töten eines Elitegegners gewährt 5 Sekunden lang eine Chance von 12% auf kritische Treffer. Max. 3 Stapel.
So not just bad translation, but straight up wrong.

Additionally, the description of “Seht meinen Zorn” (See my wrath): Schild des Glaubens gewährt Victor 60% Zorn. Peinigen fügt jetzt 40% des Angrifsschadens zu.
“Peinigen” is the translation of “Smite” here, and in the english description it fits the formulation of Righteous Fury. However, the german description of Righteous Fury calls it “Zerschmettern”, so the talent description is a bit confusing.

  1. Open Game in german language and look at Warrior Priest talents
