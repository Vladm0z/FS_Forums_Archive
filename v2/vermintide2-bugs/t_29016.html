Valve itself wants Windows games to run on Linux (and MacOS), which is why they have integrated Wine ( https://www.winehq.org/ ) into Steam using their Proton project ( GitHub - ValveSoftware/Proton: Compatibility tool for Steam Play based on Wine and additional components ). Just enable Proton by navigating to ‘View → Settings → Steam Play’ in the Linux Steam client and checking all the boxes. Then you can download, install and launch Windows games from Steam on Linux.

Gaming on Linux is much easier than 10 years ago; the DXVK project ( GitHub - doitsujin/dxvk: Vulkan-based implementation of D3D9, D3D10 and D3D11 for Linux / Wine ), which translates DirectX 11 calls to Vulkan ones, allows games on Wine to be played with near performance parity to Windows.

As for getting started, just install Ubuntu (the most user friendly distribution) and take it from there. Vermintide 1 fully works since it does not have Easy Anti-Cheat, give it a try.
