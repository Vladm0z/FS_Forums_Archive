Not sure if this may help, but I noticed stuttering and massive FPS drops when I reinstalled this game as well. After fooling with some graphics settings, I found out that this game really hates VSync, whether it’s set on your graphics card (On/Fast), or in-game.

Once I disabled VSync, I started to experience the “normal” amount of frame drops in high-stress situations, and it ran quite smoothly afterwards with no massive spikes.

I run the game in DX12 mode (and two monitors at 2560x1440 with a GTX2070, if that means anything). Also, that window that appears before the game actually launches - I ensured to click the “Settings” button at the top and set my worker threads to max to ensure the game has enough PC resources to run properly. Since I have 4 cores (hyperthreaded), I had 8 threads, so the max the game allows me to set is 6 (correct me if I’m wrong, but I believe the max threads you can set is your # of threads minus 2).

Hope this helps!
