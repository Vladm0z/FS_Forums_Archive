UPDATE 31/01

KNOWN ISSUE: [PlayStation] Corrupt Game Data (Function inflate failed with code FFFFFFFFFFFFFFFD.)Technical Support
We have now implemented a backend update for PlayStation to disable the culprit weapon illusions for Bardin’s handgun. Anyone with an illusion applied will have them unapplied, and the illusions will be temporarily unavailable until we get a more permanent fix out. The weapon illusions that have been temporarily disabled are: Zarazaz Kantuzthrag Zanthrund Aldthrund

We are aware of a Corrupt game data crash on PlayStation that can occur either during launch, or matchmaking.

The error will appear as:

Corrupt game data.

This error could be caused by a broken install. Try to re-install the game.

(Function inflate failed with code FFFFFFFFFFFFFFFD.)

This issue is caused by a corrupted texture for some of Bardin’s handgun illusions. We recommend avoiding using Bardin’s handgun until a fix is released.

If you last played as Bardin using the handgun you may be unable to launch Vermintide 2, as Bardin will be being selected by default when connecting with the backend.

Update: 3/26 Offline PS4/5 Crash/Bug Resolution

The Title Screen where you select Online or Offline states:

Please note that progress from offline mode does NOT transfer to online mode. You are, however, able to transfer your online progression to your offline account.

Normally on the same screen with that message you can press Triangle to sync your offline save.

Without PSN you can’t access the feature on the console system to Upload/Restore your saved data from the cloud server either. This menu is found in Settings (cog icon) > Storage > Console Storage > Saved Data > Saved Data and Game/App Settings on the PS5 console.
