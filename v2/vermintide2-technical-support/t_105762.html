FatsharkLevCommunity Support • 2025-03-11 13:52:27

Sorry to hear this @One_ulgy0rat

There appears to be two issues here!

Firstly, an issue with your GPU drivers has been flagged up in the logs. I recommend a clean reinstallation of your GPU drivers:
https://support.fatshark.se/hc/en-us/articles/360021233554--PC-How-to-Perform-a-Clean-Re-Installation-of-Your-NVIDIA-GPU-Drivers

Secondly, there’s a conflict between your NVIDIA GeForce GTX 950M and Intel HD Graphics 530. Sometimes with dual-GPU laptops things can get a bit muddled. If reinstalling your GPU drivers doesn’t resolve the issue, please try manually changing your adapter index (which should force Vermintide 2 to use your 950M over Intel 530). To do so:

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to AppData\Roaming\Fatshark\Vermintide 2
  4. Open your user_settings.config file
  5. Find the setting named adapter_index
  6. Change this setting value to adapter_index = 1
  7. Save your user_settings.config file
  8. Launch Vermintide 2 as usual

Please let me know how this goes!

FatsharkLevCommunity Support • 2025-03-13 09:55:21

Huh, interestingly, your log still shows your adapter_id as being set to 0.

Your GTX 950M is set on AdapterID: 1 and Intel HD 530 is set on AdapterID: 0 which is why it’s returning a no screens connected message and referencing Intel HD graphics in the error message.

Can you check that your user_settings.config file isn’t set as ‘Read-only’. To do so:

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to AppData\Roaming\Fatshark\Vermintide 2
  4. Right-click your user_settings.config file
  5. Select 'Properties;
  6. Under ‘attributes’ check that the ‘Read-only’ box is disabled
  7. If disabled, edit your user_settings.config file
  8. Set adapter_index = 1 and save changes

If there’s no change after this, please try a clean reinstallation of Vermintide 2 which involves deleting your AppData (please note any custom settings e.g. graphics, keybinds etc. will be reset):
https://support.fatshark.se/hc/en-us/articles/360034118394--PC-How-to-Perform-a-Clean-Re-Installation-of-Vermintide-2-or-Darktide

please let me know how you get on.
