JarJarBlunts • 2023-11-15 03:50:14

I found something that so far works.

I’ve only tried launching a few times, but it has worked every time when I did this.

Go to general properties for Vermintide on steam and add this to the launch options

cmd /c “set OPENSSL_ia32cap=:~0x20000000 && %command%”

Once you do that close the window and launch the game. A CMD window should open and the launcher will launch. Ignore the CMD window and launch the game and it should work. I’ve been able to quit and launch the game multiple times with this solution.
