@Kaze_ko thank you! We’ve identified that the issue is that a module download for EAC is failing.

You’re being blocked from this URL somehow:

If you can identify why that is being blocked and gain access, that should resolve the underlying issue going forwards. If you visit the URL are any errors shown?

Additionally, just to provide some updated steps to what was tried earlier, which I recommend completing to see if it helps, and to ensure your game installaton and EAC installations are repaired correctly!

Firstly, delete the EAC Certificates directory:

  1. Navigate to: C:\Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\EasyAntiCheat
  2. Delete the ‘Certificates’ directory

Next, uninstall and reinstall EAC_EOS using Powershell commands:

  1. Go to the Vermintide 2 Easy Anti-Cheat EOS directory:
    C:\Program Files\Steam\steamapps\common\Warhammer Vermintide 2\installers\EasyAntiCheatEOS*
  2. Shift + Right-click in the folder and select ‘Run Powershell window here’
  3. Paste the following command:
    .\EasyAntiCheat_EOS_Setup.exe uninstall e020ce70c5b74c38805c6f3f910bac22
  4. Press enter
  5. Then paste the followng command:
    .\EasyAntiCheat_EOS_Setup.exe install e020ce70c5b74c38805c6f3f910bac22
  6. Press enter

Lastly, Verify Integrity of Game Files:

  1. In Steam, right-click Vermintide 2 in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify the Integrity of Game Files’ button
  5. When complete, close and reopen Steam
