KNOWN ISSUE: Game Won't Launch Using Windows 10 (Ver.1607)Technical Support
@all, just to provide an update on this (sorry it took so long!) This has been reviewed internally, and due to Windows 10 ver. 1607 being end-of-life since 2019, this is a specific version of Windows 10 that we are regrettably unable to support. We can only recommend if you are using ver. 1607 to upgrade to another version of Windows 10, or to Windows 11. Apologies for any disappointment.

We are aware of an issue preventing players using an older version of Windows 10 (Version 1607) from being able to launch or play Vermintide 2.

The affected versions are -

  • Windows 10 Education (v1607)
  • Windows 10 Enterprise (v1607)
  • Windows 10 Enterprise IoT (v1607)

As a result of this issue, the game will crash on launch and display the following error (or similar to):

vermintide2.exe - Entry point not found

Entry point for procedure SetThreadDescription not found in the DLL library D:\Games\Steam\steamapps\common\Warhammer Vermintide 2\binaries\sl.interposer.dll.

Regrettably, we have no immediate solutions at this time, but we are looking into this matter.

For users who can (we appreciate not everyone can do so) we advise updating to a newer version of Windows 10, or to Windows 11.

We will be merging any existing posts relating to this issue here, to help us monitor the situation.
