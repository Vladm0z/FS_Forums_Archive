Okay thanks! Another thought, is to try launching with administrator permissions for both Vermintide 2 and the launcher. To do so:

  1. In your Steam library, locate Vermintide 2
  2. Right-click and go to ‘Manage’ > ‘Browse local files’
  3. In the Vermintide Steam directory go to the ‘launcher’ folder:
    C:\Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\launcher
  4. Right-click on Launcher.exe and select ‘Properties’
  5. Go to the ‘Compatibility’ tab
  6. Enable the “Run this program as administrator” checkbox and ‘Apply’ changes
  7. Next, in the Vermintide Steam directory go to the ‘binaries’ folder:
    C:\Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\binaries
  8. Right-click on vermintide2.exe and select ‘Properties’
  9. Go to the ‘Compatibility’ tab
  10. Enable the “Run this program as administrator” checkbox and ‘Apply’ changes

If you’re using Direct X12, then please also change the following Administrator privilege:

  1. In your Steam library, locate Vermintide 2
  2. Right-click and go to ‘Manage’ > ‘Browse local files’
  3. In the Vermintide Steam directory go to the ‘launcher’ folder:
    C:\Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\binaries_dx12
  4. Right-click on vermintide2_dx12.exe and select ‘Properties’
  5. Go to the ‘Compatibility’ tab
  6. Enable the “Run this program as administrator” checkbox and ‘Apply’ changes
