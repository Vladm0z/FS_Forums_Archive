If applying the above processes does not solve your problem, then you can follow this article; because I had the same problem with my computer. The game installation files can become corrupted.

Just follow these steps:
Open Steam > library option> Locate the game > right-click on it> Click on the Properties option> Select the Local Files > click on the Verify the integrity of the game cache option.
Then you should reinstall freshly.
