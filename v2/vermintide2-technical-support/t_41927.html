FatsharkJuliaCommunity Support • 2020-10-30 15:35:53

We’re a bit stuck with this one but what we do know is that this is related to Easy Anti-Cheat, seeing as you can play on the ‘Modded’ realm with no problems.

Firstly please check that the Easy Anti-Cheat service is enabled by:

  1. Open the Command Prompt as an administrator
  2. Enter the command:
    services.msc
  3. Locate Easy Anti-Cheat within the list and double-click it
  4. Change ‘Startup Type’ to ‘Manual’
  5. Save the changes

Next step would be to perform a a Selective Startup. This can help diagnose whether a background application is interfering with Easy Anti-Cheat. This can be performed by:

  1. Press the Windows key
  2. Type ‘msconfig’ and select ‘System Configuration’
  3. On the ‘General’ tab, select ‘Selective Startup’
  4. Deselect ‘Load startup Items’
  5. Reboot your PC
  6. Re-launch Vermintide 2 and see if the issue persists
