@Khemz sorry to hear this.

It’s difficult to pinpoint exact causes of Deadlock crashes, though there does appear to be an unusual reference to your registry and the game sound engine.

Some general things I recommend to try here:

Perform a clean reinstallation of Vermintide 2, which involves deleting your AppData. This can rule out any issue with the game installation itself or your settings (please note any custom settings e.g. graphics, keybinds etc. will be reset):

https://support.fatshark.se/hc/en-us/articles/360034118394--PC-How-to-Perform-a-Clean-Re-Installation-of-Vermintide-2-or-Darktide

If the crash persists, next please try:

  • Ensure you have latest Windows updates installed
  • Check your GPU drivers are up-to-date
  • Try repairing/reinstalling your Windows OS (I appreciate this is a more extreme measure, but just in case of corrupted OS or a registry issue)

Please let me know how this goes.
