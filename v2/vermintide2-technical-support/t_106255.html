FatsharkLevCommunity Support • 2025-03-26 11:58:21

@Nixaerie, regarding the Deadlock crash there appears to be a Steam-related error occurring.

It’s possible that the issue is voip related, but we’re not 100% certain. Can you please try disabling voip and see if there’s any difference:

  1. Press Windows + R
  2. Search for %appdata%
  3. Navigate to the Vermintide 2 directory \Fatshark\Vermintide 2
  4. Edit your user_settings.config file
  5. Locate the setting ‘voip_is_enabled’
  6. Set this to ‘voip_is_enabled = false’
  7. Save your user_settings.config file
  8. Launch Vermintide 2 as normal

Otherwise, we can only suggest to try the following:

  • Restart your PC
  • Fully restart your Steam client
  • Ensure you have latest Windows updated installed
  • Check your Steam client is up-to-date
  • Try a clean reinstallation of Vermintide 2, which involves deleting your AppData (note any custom settings e.g. keybinds, graphics etc. will be reset):
    https://support.fatshark.se/hc/en-us/articles/360034118394--PC-How-to-Perform-a-Clean-Re-Installation-of-Vermintide-2-or-Darktide

The launcher issue is different, and if you’ve tried our launcher-related solutions already you may need to rely on the launcher workaround:
https://support.fatshark.se/hc/en-us/articles/360021423613--PC-How-to-Resolve-Vermintide-2-Launcher-Issues
