@MrHarisn thanks for the screenshot. This error is different to the original AWS outage error.

AWS outage EAC error:

EOS auth status = failed.
result = UnrecognizedResponse

Your current EAC error:

EOS auth status = failed,
result = NoConnection

This error indicates that your connection is being blocked in some way. I recommend checking your network, Firewall and Anti-Virus settings:

https://support.fatshark.se/hc/en-us/articles/360007853137--PC-How-to-Resolve-Easy-Anti-Cheat-Errors#h_01JP7YSTEVHG2C39XKHCXEN3ZE

As you are based in Russia, we’ve also seen these types of errors caused by ISP or government blocks, which unfortunately we’re unable to resolve on our end.

It can be helpful to temporarily switch to a mobile data connection, or use a VPN (though I appreciate these options aren’t always possible to try) and check if the error persists; which can help to determine if the issue is network/ISP-related.
