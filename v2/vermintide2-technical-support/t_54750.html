Game Freezes randomly for 5 seconds, occasionally crashing

4 Posts • 357 Views
Z
Zephel • 2022-10-28 22:56:11

While playing solo or in a group the game will randomly freeze completely for around 5 seconds. The sound keeps playing, but that is all. Others in multiplayer will see me running in place or something of the like till it resolves. This has resulted in a complete game crash several times as well.

I’ve tried updating graphics drivers, changing DX versions, changing power settings on my graphics card, changing graphics settings etc and nothing resolves this. This did not occur till the 60GB patch. My hardware regularly runs the game at 120+ FPS on the highest settings, so I don’t believe it’s a performance issue in that right.

I’ve also disabled Steam overlay and NVidia overlays. I couldn’t really find anyone else with a thread along these lines. Any help would be appreciated!

Z
Zephel • 2022-10-29 06:48:19

Further troubleshooting found the issue. Tower of Fantasy leaves a system tray application running after close that seemed to somehow conflicted with Vermintide 2. I’d only presume that maybe a copy of easy anticheat remained active from in that caused issues. It hadn’t caused any issues before recent updates, but good to keep an eye on if anyone else runs into this issue.
