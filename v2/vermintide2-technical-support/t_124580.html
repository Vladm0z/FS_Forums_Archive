FatsharkLevCommunity Support • 2026-08-14 09:06:42

Sorry to hear that. I’ve now spoken with our backend developers and after reviewing the logs they informed me that:

  • One log includes an unusual issue on our backend service provider’s end. We received unexpected data when calling their API and received a ‘500 Internal Server Error’. Unfortunately, this isn’t something we can resolve and is down to instability from our service provider
  • Two other logs contained an error ‘PEER_FAILED_VERIFICATION’ after making requests to the backend. This means that client did not trust the SSL Cert issued by our backend service provider’s servers. This could be a symptom of:
  1. Incorrect system time (date and time of client is not correct)
  2. The server is using old/incorrect certification - which is unlikely otherwise all players would encounter this issue
  3. Client/ISP is trying to eavesdrop on the conversation/requests
  4. Client network problems resulting in corrupt/lost data packages or similar

Regrettably, as the issues appear to be with either our backend service provider, or client side, there isn’t anything specific that we can do on our end
