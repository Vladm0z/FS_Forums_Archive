FatsharkLevCommunity Support • 2025-03-13 09:34:19

Unfortunately, no We haven’t received widespread BSOD reports after the update, so this appears to be more of an isolated incident.

You could try uninstalling and reinstalling EAC, which can be done via Powershell commands.

To do so:

  1. Go to the Vermintide 2 Easy Anti-Cheat EOS directory:
    C:\Program Files\Steam\steamapps\common\Warhammer Vermintide 2\installers\EasyAntiCheatEOS
  2. Shift + Right-click in the folder and select ‘Run Powershell window here’
  3. Paste the following command:

.\EasyAntiCheat_EOS_Setup.exe uninstall e020ce70c5b74c38805c6f3f910bac22

  1. Press enter
  2. Then paste the followng command:

.\EasyAntiCheat_EOS_Setup.exe install e020ce70c5b74c38805c6f3f910bac22

  1. Press enter

Lastly, Verify Integrity of Game Files:
https://support.fatshark.se/hc/en-us/articles/360021233534--PC-How-to-Verify-Integrity-of-Game-Files-via-Steam
