Issue Description (Required):

My friend and I are encountering the following issue: After completing a few levels (the exact number varies depending on difficulty - we usually play various deeds like Vanguard, Specials, Hordes, or combinations of these on Cataclysm, and in this case it’s 3-4 missions; on missions with a lower number of enemies, it takes more time), the game displays a “lost contact” message for all non-host players, removing them from the session (and the host has a noticeable fps drop at that moment). Once this begins, it occurs on nearly every map (when boss or horde spawns) except the shortest ones, ending the deed if it’s not the host’s deed (and most of the time it’s not). Removing the shader cache and clearing all other caches temporarily mitigates the problem, allowing us to play for a few days before the issue recurs. However, having to delete all caches every few days is a bit annoying.

Prior to version 6.7.0/6.6.0, instead of disconnecting non-host players, there would be enemy animation glitches - one enemy in a group of 30-40 skipping animations (moving without sound or animation, teleporting instead of jumping, etc.) - which was frustrating but at least didn’t end the deeds.

Before version 6.0.0, we never experienced this issue, but every update since 6.0.0 has progressively worsened the problem.

In modded play, the issue differs slightly: non-host clients only see their hp changes and nothing else - they cannot interact with enemies or sometimes even see them, though they still can move. It looks like the host receives all/most of the client inputs (movement, attacks, etc.) but only sends back health values to clients.
