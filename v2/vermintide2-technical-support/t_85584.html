To do so:

  1. Get the latest release (etwpackage1.58.zip as of today) from Releases · google/UIforETW · GitHub. This is an open-source tool from Google to record and manage Event Tracing for Windows (ETW) traces.

  2. Extract the contents, and run etwpackage\bin\UIforETW.exe. This will install the necessary versions of the Windows Performance Toolkit.

  3. Ensure that [Tracing to file] is selected. (See screenshot below.)

  4. Boot the game, and prepare a situation in which the issue can be reproduced…

  5. Press Ctrl+Win+R to start a trace. Wait 2 Mississippis.

  6. Reproduce the issue that cause performance drops.

  7. Wait 2 Mississippis. Press Ctrl+Win+R again to stop the trace.

  8. You can then right-click the trace and select Browse folder to open the Documents\Etwtraces folder containing the traces.

  9. Please proide us with the .etl file for the trace.
