Sorry to hear this @Checkmate50

There are a few things worth checking based on data in your logs:

Firstly, please add appropriate Anti-Virus and Firewall exceptions for both Vermintide 2 and Easy Anti-Cheat:

  • vermintide2.exe in \Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\binaries
  • vermintide2_dx12.exe in \Program Files (x86)\Steam\steamapps\common\Warhammer Vermintide 2\binaries_dx12
  • EasyAntiCheat_EOS.exe in C:\Program Files (x86)\EasyAntiCheat_EOS

Next, perform a ‘Selective Startup’ to disable background applications in case external software is conflicting/being flagged by EAC:

  1. Press the Windows key
  2. Type ‘msconfig’ and select ‘System Configuration’
  3. On the ‘General’ tab, select ‘Selective Startup’
  4. Deselect ‘Load startup Items’
  5. Reboot your PC

If the error no longer occurs after having performed the Selective Startup, try re-introducing your programs one-by-one to determine which is causing your issue.

Lastly, could you please try disconnecting any additional input devices e.g. Xbox controller, and then check to see if Offiial realm launches correctly?
