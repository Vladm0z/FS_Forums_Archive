I too don’t believe this is an audio issue, I think something else is at play here!

Could you try performing a clean re-installation of your GPU drivers using the instructions here?

If unsuccessful, run a Selective Startup and see if there’s any improvement by:

  1. Press the Windows key
  2. Type ‘msconfig’ and select ‘System Configuration’
  3. On the ‘General’ tab, select ‘Selective Startup’
  4. Deselect ‘Load startup Items’
  5. Reboot your PC
  6. Play Vermintide 2 as normal
