first try to locate “shader_cache.pipe_lib” and delete it, it’s part of the settings user data Directory so where settings and saves are located, reinstalling or verifying your game won’t mess with them as they are located separately.

to do that press win+R insert %appdata%

should be as follows: C:\Users\NAME\AppData\Roaming\Fatshark\Vermintide 2

Delete shader_cache.pipe_lib, start the game it should prompt it to create new shader file on start up, this usually takes up to a couple of minutes, just let it run its course.

So, I did this, but the problem still persist. But I found a work-around, sort of temporary fix, so I noticed that the display mode switches right after the game starts, not before (I have two display modes, Optimus and GPU only) so I tried switching to GPU display only before I launch the game, then suddenly, the screen mode and video setting problems disappeared, so I set the launcher on automatic display switching on NVIDIA control panel to compensate for the display mode not switching before the game opens. It works, but I don’t know why the game suddenly runs before the display mode change, it suddenly does that. And also, the temporary fix that I found for FPS drops when there are steam pop ups or overlays are the Triple Buffering feature in NVIDIA control panel. Still, I don’t open them by default, and they run perfectly fine before, but I’m glad I could still play right now.
