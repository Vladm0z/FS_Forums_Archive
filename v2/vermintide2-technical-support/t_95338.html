Hi @thedwarrowdelf,

I recommend to try verifying integrity of game files:

  1. Right-click Vermintide 2 in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify the Integrity of Game Files’ button
  5. When complete, close and reopen Steam

Failing this, please try a clean reinstallation of Vermintide 2:
