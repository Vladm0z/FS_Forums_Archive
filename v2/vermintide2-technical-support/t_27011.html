FatsharkJuliaCommunity Support • 2018-09-07 10:42:07

That’s a shame! Let’s make sure Easy Anti-Cheat is enabled within your ‘Services’. This can be done by:

  1. Navigate to the Task Manager
  2. Select the ‘Services’ tab
  3. Select the ‘Open Services’ button, located at the bottom of the window
  4. Locate ‘EasyAntiCheat’ within the list
  5. Right-click it and select ‘Properties’
  6. Change ‘Startup Type’ to ‘Automatic’
  7. Save your changes
  8. Reboot your PC
  9. Launch Vermintide 2 as normal

Should this prove to be unsuccessful, you may need to contact Easy Anti-Cheat directly. They’ll be able to provide the best advice in this situation: https://www.easy.ac/en-us/support/vermintide2/contact/tech/

Be sure to include as much information as possible in your message to them, and please let me know if there’s anything I can help with.
