Hi,

I am experiencing consistent crashes when trying to run the game in DX12. At first it was intermittent and often (crashed about 3 times in the span of 20mins once) both during a game and in the keep, but now I cannot load into the keep at all after starting the game.
Crashes are CTDs, sometimes taking the audio out altogether and I’ve noticed that if I don’t manually reboot quickly after those my PC will lock up and a hard reboot is needed.
I realize there are plenty of other threads out there about this issue, but I am posting this to provide as much info as I can to help identify the cause.
I have no issues playing the game with DX11, other than the occasional crash that occurs after exiting the game, which I’ve had happen on my previous system as well.

My specs:

  • AMD Ryzen 3700x (stock)
  • Gigabyte Aorus RTX 2070 Super (factory and manually OC’d)
  • Gigabyte Aorus X570 Master
  • Crucial Ballistix DDR4 3600 Mhz (XMP profile on)
  • Windows 10 Pro - installed on Samsung 970 EVO M.2 NVME (Steam and Vermintide 2 installed on Samsung 860 EVO M.2)

Things I’ve tried:

  • running the game with different # of worker threads (between 6 and 10)
  • running the game in fullscreen and borderless window
  • completely reinstalling GPU drivers using DDU (driver version 446.14)
  • running the game with and without the GPU manual OC (by closing MSI Afterburner altogether)
  • using different power management plans from the NVIDIA control panel (Adaptive and Prefer Max Performance)
  • running game with and without info overlays like RTSS
    (in terms of other overlays: I have Steam overlay turned on in all games, I do not have GeForce Experience installed, and no recording software like FRAPS or Xbox GameBar running)
  • running game with and without monitoring software like HWInfo running in the background
  • enabling and disabling Windows 10 Fullscreen Optimizations in the Compatibility tab
  • verifying integrity of game files in Steam
  • running memtest86 to verify there are no errors with my RAM or XMP profile
  • adding both Vermintide dx11 and dx12 binaries as excluded processes in Windows Defender
  • temporarily disabling Windows Defender real-time protection
  • deleting DirectX shader cache via Disk Clean-up
  • setting Vermintide dx12 binary to run as administrator in the Compatibility tab
  • running dxdiag to confirm no errors reported

Things running in background:

  • Corsair iCUE (mouse and keyboard)
  • SteelSeries Engine 3 (headset)

I’ll include a couple of my crash dumps below. I’ve also taken a look at a couple of the console logs created in sessions that ended with a crash and it looks like there is some sort of access violation being reported. Don’t know if that might have anything to do with the game and shader cache being on two different drives.

If there’s anything else I can provide here, please let me know.

Thanks!
