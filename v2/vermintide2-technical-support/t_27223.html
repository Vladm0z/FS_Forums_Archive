SirBattleCat • 2018-09-15 00:00:31

Finally solved the problem. For some reason Windows hadn’t been installing updates. In fact when I went and wanted to look for updates I was told I couldn’t install updates because my PC was turned off (I’m not kidding). I figured out that I was missing a major build update for Windows and found a separate installer for the newest build on Microsoft’s website. After installing that, everything works perfectly.

So it seems error 0xc000142 really does mean that system files are missing. Just posting the solution here in case anybody else happens to have the same problem.
