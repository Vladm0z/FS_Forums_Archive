Just to add to this, one of our developers has implemented additional options to the launcher workaround so that Modded realm can now be selected (it may require a Steam restart to be visible). Unfortunately, this does come with limitations in that mods cannot be added or re-arranged, but at the very least it does allow access to Modded realm now.

image502×447 48.5 KB

As the launcher pulls data from Steam and fills the user_settings.config file in a very specific way, in order for mods to be added/re-arranged etc. it would require reconstructing a lot of data manually and a single mistake would cause the engine to reset all settings. Due to this, we can’t really provide any clear or simple instructions on how to manually edit mods when using the launcher bypass.
