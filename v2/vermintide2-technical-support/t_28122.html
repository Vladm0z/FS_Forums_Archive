Hey Zyba, this error indicates that one of your DLLs is corrupted. Solutions include:

  • Reinstall the Visual C++ 2015 Redistributables
  • Run the Windows System File Checker
  • Re-install Vermintide 2
  • To identify the precise DLL that is causing an issue, download the Microsoft Dependency Walker and open vermintide2.exe with it. The libraries with a red icon represent the corrupted ones

If you need help with any of these options, please let me know.
