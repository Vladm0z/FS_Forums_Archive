Ah I see! Thank you for the update. Glad to hear the issue is resolved

Though the game synchronizes with the backend, the DLC logic check in the backend is:
Is the DLC OWNED? If yes, check ACTIVE
Is the DLC ACTIVE? If yes, allow access

However, the DLC active check is decided entirely by the local console setting. So, it’s possible to have DLC enabled/disabled separately across consoles depending on each console’s settings.
