Issue Type (Required):

Other

Issue Description (Required):

Simple, really. If anyone joins the server / game while it is loading in a new map or switching sides, the load will never be finished and people are forced to ALT+F4 quit. Didn’t seem to be reported yet, so here it is.

Really annoying, ends game sessions often.

Steps to Reproduce (Required):

  1. Enjoy any random game of Vermintide Versus.

  2. Midmatch the map / side switches.

  3. Player joins your game mid load.

  4. The server gets confused and eternally loads the game.

  5. (sometimes) waiting long enough (5 minutes and such) it will get it right and continue. Often it does not.

Reproduction Rate (Required):

Common (<50%)
