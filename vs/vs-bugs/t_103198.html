Issue Type (Required):

Gameplay

Issue Description (Required):

hooking a person at the same time with another hookrat will result into one of the hookrats having a ghost hook attached to the person. This needs to be done from the same direction and within the possible dragging animation angle otherwise one of the hookrats will not connect or be stuck in an hooked animation as if hooking a hero that would get downed due to it.

  1. Hooked state behaves absolutely normal if the 2 hookrats drag the person in the same direction. Trying to do so in the opposite directions of the possible drag angle will result to both of them being unable to move.
  2. Killing either one of the hookrats will not result into the hero being free of the hook, the one still alive will have full control after that.
  3. The hookrat with the ghost hook attached to the hero can not initiate the hook-up animation, only the hookrat with the actual hook attached can. Doing so will result in both the hookrats initiate the animation and after that all’s normal. The hookrat with the ghost hook can initiate the animation if the hookrat with the actual hook attached dies.
  4. It’s about timing and not ping of either the hookrats or the hero player from what we’ve seen so far. It’s way easier to do this if the hookrats are a bit distanced from each other.
  5. both the hookrats deal damage and the damage from hook is attributed to both the hookrats twice.
  6. As seen in the video, the hero goes slightly into the air and I think it corresponds to the distance between the hookrats. This can make it impossible for other heroes to free the target afterwards.

Steps to Reproduce (Required):

  1. Have 2 hookrats time their hook together on the same target from the same direction.
  2. If done correctly, both the hookrats will connect.
