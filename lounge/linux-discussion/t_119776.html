immron • 2026-03-23 19:51:55

Might be an issue with filepaths. I had the same issue, pop_os, using flatpak steam. What solved it was moving the files but its a bit tricky with the flatpak. Suppose using deb steam could solve it but heres what i did to get it working with flatpak

Create folder under home as /home/user/games/steamlib
Install flatseal (i needed to start via terminal using “flatpak run”)
Under Steam in flatseal add the above new folder. Also add perms so its /path/to/steamlib:rw
Add the new folder in steam settings as a library
Move Darktide there

Hope it helps!
