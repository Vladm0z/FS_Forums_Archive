Phantomshotgun • 2026-03-13 15:04:55

Linux user here. Darktide was never really optimized for Linux but it has the barest functions working. I use Kubuntu, a distro based off of Ubuntu with a layout no different from windows in feel and UI. i also use a AMD 7700 CPU and 7700 GPU and AMD does work better with linux and always stays up to date. Darktide for me works just fine, save for some graphical issues I’ve later solved, but I have to ask a few questions.

  • Are you using Wine, Winetricks and Protontricks?
  • have you validated the files to make sure nothing is lost?
  • did you store the files in a folder you have ease to access?

Wine is a linux open-source project that provides a compatibility layer to windows programs to run in a simulated windows environment on a different OS, such as Linux or macOS. It’s not so much ‘emulating’ windows and more creating a space with a basic windows structure, if you ask me. More experienced users might know more then I do.

Winetricks is more a workaround for issues with Wine, itself. it can be used via commands or a GUI, and adds the ability to easily install missing DLL’s, applications, fonts, and other abilities to edit and tune your Wine.

Protontricks is more a wrapper for Winetricks to work with proton. it’s the same idea but for proton games; adding missing DLLs, apps, fonts, tweaking, ect. Personally i feel it’s a critical tool for linux gamers to have just in case you’re missing a DLL for a app to work. Now any game designed to work on linux natively or optimized for linux might not need protontricks, or even needs proton, but in most cases it’s should be installed for games having trouble running on proton alone.

(on a side-note; you need Protontricks if you ever want to mod games like Fallout 4 or Cyberpunk 2077, as you’ll need DLLs and programs like C++ installed to use the more complex mods.)

For my Darktide, i use GE-Proton10-32 (flatpack). it’s hardly ever crashed on me for hour long gameplay, but I also use a custom launch command to make my game work as well. for most linux game issues it’s a problem with the launcher and you might just need a launch command for your Darktide.

RADV_PERFTEST=video_decode RADV_DEBUG=nodcc DXVK_ASYNC=1 %command%

This just helps with my issues with launching and also used for graphical issues as well. If you experience any issues with graphics, such as potato quality meshes or your las gun looking like polygons, this is an issue with Fat Shark not knowing how to optimize for linux users and the game assuming you’re using a SteamDeck or something else and just throttling your default GPU limit settings. You can read my post here on how I fixed that issue "Mesh Streaming" still not working for ryzen 5 series users - #8 by Phantomshotgun

Oh yea, if you need to look through and edit code, and notpad isn’t enough, look into installing Kate. It’s like Notepad but with more bells, whistles, a history search, and able to read active log files.
