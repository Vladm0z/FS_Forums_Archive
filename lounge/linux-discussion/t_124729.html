Take cachyOs. That’s not because it is european, even if at first I wanted to test it because I wanted to stay away of everything made in USA. But to explain the why, I started with fedora and got strange bugs in games.
At first, I have think that it was linux and I have not given up because… I did not want returning Windows.

When I created the computer for my son, I have put Bazzite. Why? because I wanted the less maintenance possible, and so an immutable image was the best in my eyes.

Bazzite has old drivers… AMD and Nvidia… CachyOs is a rolling release… you get immediately any update. And don’t be afraid by the fact it is in the Arch linux branch. You can use an IA if you’re lost, and CachyOs is as easy to understand as is Fedora or Bazzite.
The system installs itself with KDE or gnome or whatever you want.
In fact you have more choice in the CachyOs install than in a Bazzite install. I just advice to put GRUB if you want to install several system. Just easier to handle things, but Limine is good also.

I precise, because I follow now a team on youtube that you have others options:

  • SteamOS was on Ubuntu (if I remember well) and now has switched to Arch Linux. So the same base as CachyOS.

The difference between the 2:

  • CachyOS is a rolling release. It means you’ll get immediately the updates. It means also you have to update all the time (I update sometimes 2 or 3 times a day). However, don’t feel forced to update. Updating every week is sufficient
  • SteamOS is an immutable image. So like Bazzite. It does not allow to install native app, but you still can install flatpak packets. It means it will take more more space on your drive. Tbh, I have not tested it… but I would test it if I wanted a immutable image, unless I feel that the OS below can do the job.

And there is also

  • GLF OS - French and based on NixOS. Seems to be good and made for ex windows users. NixOS is special (this will be the basis of the Linux of the french administration) as it permits to deploy an OS image really fast (that’s why the french administration will use it… 15 min to configure a working station).
    But that’s not what you need to know… what you need to know is that this OS has been made to be friendly for an ex windows user and optimized for gaming. It is also immutable and you can easily rollback (it means that if something go wrong, you can easily restore a previous image).

I stay with CachyOS because it is easier for me to maintain all computers at home (3 desktop and 1 laptop) and because I made a script (with the help of Gemini and Claude) to install automatically everything I want on my computer and set everything ready to use. It means I launch the install. I come back. I reboot the computer. I launch my script and go watching TV. 20 minutes later, everything is installed and ready.
Also, I have succeeded to configure the secure boot with it… and I don’t want to get a headache at trying to do it on a different distro.
