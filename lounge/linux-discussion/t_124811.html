i submitted a request to steam support and i havent attempted this myself yet since im reinstalling the game and its 5 hours left from finishing, but this is the response i got; if anyone else having the same issue as me does this and it works, please let me know!

Please start by trying these steps in order:

  • Revert or disable any changes you’ve made in the BIOS or via third party utilities. These changes may be affecting your system’s performance and/or stability.
  • Check that your Deck’s OS is up to date by pressing the “Steam” button > Settings > System and then under “Software Updates” select “Check for Updates”. If an update is available, please select to Install/Apply. Once that is done applying, fully shut down the unit by going to the Power menu and select “Shutdown” and then retest the issue.
  • If the issue persists, try forcing the game to run with Proton by pressing Menu with the game selected in your Library, then going to Properties…> Compatibility > Force the use of a specific Steam Play compatibility tool, and selecting the most recent Proton version. If you experience the same problem, try selecting the previous Proton release instead.
  • If the game is stored remotely (on a microSD card or other external disk), move the installation to the Steam Deck’s SSD and retest. You can move an installation by going to Steam > Settings > Storage, selecting the game, and pressing Y to select a new location.
  • Verify the integrity of the game files by highlighting the game in your Library and using the option in Menu (button) > Properties… > Installed Files.
