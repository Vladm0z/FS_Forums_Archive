2. Find the logs

Darktide SteamID: 1361210
This is the ID you require to navigate in the “windows” folder of your steam app.
You can see this reference in the url of the steam page of Darktide.

To find the logs, you must go in the equivalent of Windows files. Steam reproduces the environment in compatdata folder.

Go to steamapps folder and navigate to:

/SteamLibrary/steamapps/compatdata/1361210/pfx/drive_c/users/steamuser/Application Data/Fatshark/Darktide/console_logs/

Find the correct console-xxx.log file and join it to your bug report.

Settings for Darktide

Disclaimer

This post is entirely written from my personal experience… and with the help of Gemini.
I have asked to all AI of this world, or close to that… I have seen incredible answers… but the only AI that was smart enough was Gemini.

1. Drivers

If you plan using AMD, drivers are part of the kernel. However, using a Bazzite distro is not the same of a CachyOS distro. Keep that in mind. There is a delay between updates on the Fedora branch (Bazzite - Nobara - Fedora - Updates every 6 months).
I had to remove Bazzite on one of my computer exactly because of this. Darktide was crashing with Bazzite and with an AMD GPU. Once I have installed CachyOS, the crashes stopped.
Nota: Don’t think I say Bazzite is bad. Bazzite is good, in fact. What I underline here is that Bazzite is slower to get updates than CachyOS.

Gaming Distros
  • CachyOS - Based on Arch Linux. Rolling Release. It means you get updates as they are available.
  • SteamOS - Based on Arch Linux but modified by Valve. Immutable image. This means you cannot install native apps and have to use Flatpak and that you won’t get updates immediately (when Valve decides to release a new image).
  • GLF OS - Based on NixOS. This distro is made with the spirit to help ex windows users to enter in Linux world. This is also an immutable distro with a rolling back system that permits to restore a previous version easily.
  • Nobara - Based on Fedora. This distro is optimized for gaming with semi rolling updates. It means that updates are not every days but every 6 months with security updates between cycles.
  • Bazzite - Based on Fedora. Immutable. Semi rolling. This distro is optimized for gaming, like Nobara (but different optimizations). Updates are not every days but every 6 months with security updates between cycles.

2. Settings

2.1. Nvidia

Frame generation works (but available only with RTX series 4 and above).
Be aware that Ray tracing can cause crashes. However, I discovered that Ray traced Reflections works but RTX global illumination cause crashes. It occurs when the game wants to use more than the vram available.

2.2. AMD

I will try to test Ray tracing on my son’s computer and would put the parameters if I find them - I have not tested on his AMD GPU setup

2.3. Intel CPU

If you have a modern intel CPU with E-cores and P-cores you should use, in launch options:

gamemoderun %command%

This will permits your computer to prioritize P-cores. All distros I quoted have this feature. I don’t know for the other distros.

3. Mods

I cannot advice enough to put this in the launch options if you use mods:
--lua-heap-mb-size 2048
This option permits your game to reserve 2 Gb of RAM to run LUA scripts. If you use mods and don’t put that, you couldwill run into crashes.
