Modder Zaphio posted instructions on how to search for voice lines with some code he developed and the posted in Squirrel Squad here:

VT1&VT2Search and play any dialogue
For y’all content creators out there, you can play any dialogue via commandlets.

Presented as a snippet for convenience.
EDIT: To use it, install Execute Lua Ingame (by prop joe) and select Search and play dialogue from the dropdown.

/soundsearch [search terms] — Search all captions for the search terms (case insensitive). The search terms must appear as typed in the same order in the subtitle. It’s recommended to open the dev console (in the VMF options for VMF itself) for easier browsing of the results).

/soundplay [number|event name] — Play a dialogue event. You can either specify an index into a previous soundsearch or type out the internal name (eg, pwe_activate_ability_handmaiden_03).

Gist: VT Snippets
