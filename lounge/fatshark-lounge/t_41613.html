Dedicated servers do not prevent high ping. Your ping relies not only on internet connection speeds but the physical distance between the source and destination systems.

Dedicated servers for V2 will not help with latency issues. There’s roughly 3k players in V2 at any given time spread out all around the world.

Dedicated servers will only make things worse for a lot of people living in areas where there is not a high number of V2 players.

Besides, no one can guarantee that the person running the server has the bandwidth and internet speeds required for a smooth game.

Also, dedicated servers cost money. Who do you think pays for that?

If you haven’t figured it out, it’s the players that have to pay for the service.

  1. The ping you see in L4D2 is not the same number as the one you see in V2, which is based on more than just the connection time and usually higher, at least 30-40 with people in the same CITY.

  2. L4D2 can run on a toaster nowadays while V2’s AI director makes a lot of host CPUs sweat.

  3. Due to the above, a dedicated server for V2 would be pretty expensive to run considering it only hosts 4 players.

  4. Official dedicated servers can still be down (happened in L4D2)

  5. There is no guarantee that you’ll be finding players on a dedicated server near you, just like there is no guarantee that you’ll be finding p2p players near you

  6. L4D2 currently has ten times the active players due to a recent update (and being free to keep for a while), so you are obviously going to have an easier time finding runs near you by sheer probability

Now obviously they could still give players the CHOICE to run their own dedicated servers, but that’s a separate headless (no graphics) version of the game to be maintained and that’s a hassle Fatshark did not want.
