FatsharkJuliaCommunity Support • 2025-04-28 10:43:25

We are aware of issues impacting players using the AMD Radeon 6000 - 9000 Series GPUs, including low GPU power draw and substantial drops in performance.

In early April, we raised this issue with AMD, who are now conducting an internal investigation. We’re also exploring the issue on our side.

In the meantime, we would really appreciate it if those who are using the AMD Radeon 6000 - 9000 Series GPUs and experiencing issues in Darktide could answer the questions below:

  • Do you have SMT (Simultaneous Multithreading) enabled?
    • IF YES: Is there an improvement with it disabled?
  • Which driver version are you using?
  • Do these issues occur only in Darktide?
  • Have you confirmed that all redundant GPU drivers have been uninstalled? This is especially important if the current GPU is an upgrade and another GPU was previously installed in the same PC

Thank you for your support as we investigate this issue with AMD.

UPDATE 05/06

INVESTIGATION: Poor Performance & Power Draw Issues Impacting AMD Radeon 6000 - 9000 Series GPUsPerformance Feedback
Update from AMD: We’ve identified an issue when compiling RT pipelines and have a developed a work around. The issue is causing stutter after loading into an area for sometimes 15 seconds or more (depending on CPU/etc), like the Mourningstar hub or any of the training levels in the Psykhanium, like Basic Training. This issue would affect 6000-9000 series cards. Users who fully disable ray tracing should not be affected by the issue and can do that to avoid the core issue if they don’t mind not…
