I know this has been reported before, but has only started occuring to me recently (past 2 weeks or so).

There was a slight performance improvement with the release of “No Man’s Land”, but has been steadily declining since. This includes serverside performance (from my experience).

Now with recent weeks, when large amounts of enemies spawn (>50) at once, my game either freezes or drops to single digit frame rate.

I have tried a large number of performance improvements options:

  • lowering all graphics settings
  • using FSR and frame generation
  • running in lower resolution
  • running in lower resolution and using FSR
  • rebuilding shader cache
  • verify integrity of game files
  • community suggestions for [application_settings] by Vizra
  • replacing direct storage version
  • VFX reducing or replacement mods
  • Zipit mod (did not appear to work)

While there may have been gains elsewhere in FPS, the issue with freeze or single digit frames with enemy spawning still persists.

While I do seek a solution, it is not terribly important and I just want to raise awareness of the issue.
