Issue Description (Required):

When using shops on the Mourningstar (Brunt, Hadron, Melk) or adjusting player loadout/talents/masteries there is a significant performance drop that persists after the menu is closed. A less significant but still noticeable performance issue is triggered by using a mission board. When using multiple menus in sequence framerate can drop to slideshow levels, and frame generation seems to cause stuttering where later frames are interpolated entirely incorrectly in a way that alternates continuously between the earlier and later sequences of frames. This issue seems to be mostly mitigated by moving the character over to a corner and waiting a few seconds for culling of off screen objects/textures before opening another menu or launching a mission. There is a less pronounced performance impact from the end of mission screen, but going through the end progression for multiple matches can also cause significant performance issues particularly when combined with other stores or menus. This is entirely reproducible and is always cleared when restarting the client until a menu (other than the character select) is pulled up.

Attempted Solutions (Optional):

I did not experience issues or this severity when I was using a single 4K 240hz display in place of Nvidia 3x1 surround. It may be related to output resolution, DLSS render resolution, Nvidia surround, or some combination of the above with my graphics settings.
