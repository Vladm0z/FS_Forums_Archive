If it’s any consolation Darktide is the exception to everything performing well on your new setup. My 9070XT has been a peach and even handles some mild undervolting no problem.

I recommend setting textures to medium (high causes pop-in for anyone with any card) and setting lowering global illumination if you’re not using RT (the baked lighting probes were made with RTX cards, not sure if that’s relevant or not). Screen space reflections also always seemed oddly performance heavy so I turn those off personally.

Disabling the mesh streamer can help with stutter at the cost of player portraits and cosmetic icons loading in slower. Go to Warhammer 40,000 DARKTIDE/bundle/application_settings/settings_common.ini and find this block:

mesh_streamer_settings = {
	disable = false
	eviction_timeout = 5
	frame_time_budget = 1
	io_buffer_budget = 10240
	limit = 700
}

Change disable = false to disable = true and then save the file. This file will get reset every time the game updates. It also may not work as well if you’re doing any other .ini tweak shenanigans so beware.

murphIV:

go into adrenalin and set the graphics for darktide to HYPR-RX

Don’t do this actually, FSR4 is enabled by default so you don’t have to worry about that and Darktide really hates being messed with by outside programs. Plus HYPR-RX enables anti-lag which at least on 6000/7000 cards is what causes the psyker shields to turn into rainbow mush.

I recommend leaving Darktide on the default profile in Adrenaline due to how the game bounces between different .exe’s. Adrenaline will more often than not point to the wrong .exe.

DTAdrenaline785×202 49 KB

I’ve seen it point to everything from the launcher, gpudetection, crash handler, and shader cache builder. This isn’t really an issue with Adrenaline itself but rather no other game bounces between different exes like Darktide does. Like the launcher runs gpudetection multiple times to find your GPU and then check its features.

What makes this worse (I think) is how if you check your launcher log it shows the launcher starting darktide.exe but it then runs the shader cache builder afterwards. This is probably why Nvidia users running the DLSS updater also get caught on the launcher. NO OTHER GAME DOES STUFF LIKE THIS.

One side effect of the game confusing adrenaline is if you’re using the overlay to see if FSR4 is working it won’t show it properly because it has the wrong exe. Darktide also doesn’t update its menus to show which version is running like other games.

Despite this it it working. Go to the psykanium and you can see whether or not the ambient particles smear across the floor grate.

FSR3Smear1236×617 112 KB

FSR4NoSmear1446×579 125 KB

it’s working and you can tell

One last issue that effects everyone but is just one more issue for AMD users: The shader cache builder is broken and doesn’t build all PSOs. You’ll have some shader stutter here and there. You can help it a bit by going to the psykanium and spending 30 seconds turning enemies into paste, tossing grenades, and making the flamer/tox flamer tanks blow up. It will get better over time but there’s not much to do besides tough it out for a few games.
