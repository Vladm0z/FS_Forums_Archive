The same for me, given the number of complaints surrounding AMD GPU’s there seems to be some underlying problem with their Direct-X rendering whereas Nvidia is fine making this game basically an Nvidia only title.

Curiously through SteamOS with its combination of Direct-X 12 to Vulkan conversion along with the Valve AMD RADV driver appear to solve the problem with performance being far more consistent without the random slowdowns.

I would like to see a Vulkan renderer in Darktide to see if performance stabilizes for AMD/Intel GPU’s but I doubt Fatshark would assign the resources.

As a long shot option maybe Fatshark could add DXVK into the game (the translation tool Valve uses), there are Windows builds of it, have it as experimental Vulkan option within the game to give us a chance of maybe easily addressing the problem.

If it doesn’t help at least they tried and the cause of SteamOS normal performance for AMD is more down to RADV and Linux.
