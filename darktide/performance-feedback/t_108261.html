Recently since last patch the game will run fine, but randomly while playing (this can be while playing a map or on morningstar) it will start to stutter hard when moving the camera, if you stay still it wont stutter. It is not an FPS issue, hard to explain, but is not something throttling or hordes spawning, is like something breaks and the only way to fix it is restarting the game. Once i do that it will run smoothly until it happens again, until next map (for now at least). This can be on any difficuly (have not tested with the first 2).

I have noticed that when on The Morningstar psysics on your character from cosmetics will go crazy when it stutters, flying everywhere. I don’t know if it is a bug related to physics suddenly bottlenecking because of a bug or if the bug makes physics go ballistics.

This happens with no programs running on the back, only steam and discord (but has happened to me with discord closed), and open razer driver (will try to test with it closed).
Steam overlay is disabled for Darktide and i am using my monitor FPS counter to check FPS.

FPS hangs around 90 to 120 fps normally, up to 60 FPS on very intese scenes sometimes (big hordes, specialits, psyker smite, etc at the same time). No FSR or Frame gen activated, no Vsync, no RTX, Framerate ulimited. Once the Bug happens changing video options do nothing to fix it, so again, is not and FPS per se issue.

I have mesh stream off (true) changed and portrait rendering off.
I have already tried to reinstalled the game with no luck.
