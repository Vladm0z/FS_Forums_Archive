I have the same setup (except a 9800x3D) and you have linked my attempted solutions.

Make sure that you have saved the config files.

Also, I have found from testing the enabling Anti-lag for Darktide helps significantly with smoothness and responsiveness for Darktide. And for complicated reasons to do with the FFX Swapchain, I recommend enabling frame generation. It doesn’t just add frames, because of how FSR is implemented it also is clearer in motion and helps with performance consistency.

Hope this helps
