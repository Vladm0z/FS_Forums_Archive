Social menu roster shows the default portrait frame instead of the equipped one

1 Posts • 19 Views
L
LucLeto • 2026-08-24 11:51:56

Issue Type (Required):

UI & UX

Issue Description (Required):

In the Social menu roster (Friends / The Mourningstar / etc.), a player’s entry shows the default portrait frame instead of the frame they actually have equipped. Opening that same player’s social popup shows the correct equipped frame, so the data is present, only the roster list renders the wrong one.

The entry is correct when it first loads and then degrades: after a profile update arrives it drops to the default frame and never recovers while the menu stays open.

Cause, from the shipped Lua:

SocialMenuRosterView._update_portrait_frame calls _queue_icons_for_unload (queuing the previous frame icon with ViewSettings.icon_unload_frame_delay, which is 0) and then starts the replacement Managers.ui:load_item_icon in the same frame. For an already-cached icon that load calls _cb_set_player_frame back synchronously, so the new material_values.portrait_frame_texture is in place immediately. On the next update, _unload_icons unloads the queued old icon, firing _cb_unset_player_frame bound to the same widget, which resets material_values.portrait_frame_texture to RosterViewStyles.default_frame_material, discarding the frame that was just resolved. It never recovers, because only a character_id change re-runs _load_widget_portrait. ViewElementPlayerSocialPopup is unaffected: _update_portrait calls unload_item_icon directly instead of using a delayed queue, which is why the popup shows the correct frame for the same player.

Steps to Reproduce (Required):

  1. Open the Social menu and go to a roster tab listing other players (Friends, or The Mourningstar).
  2. Find a player with a non-default portrait frame equipped, their entry shows it correctly at first.
  3. Leave the roster open so profile updates arrive for the listed players.
  4. Click that player’s entry to open the social popup and compare the two portraits.
  5. The roster entry shows the default frame; the popup shows the correct equipped frame.
