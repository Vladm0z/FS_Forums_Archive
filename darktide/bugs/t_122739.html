Issue Description (Required):

I was testing weapon damages for Bolt Pistol (Mark IV) and Heavy Stubber (Mark II) in the meat grinder before the update and happened to have the damage numbers recorded. I noticed a significant 50% damage drop on both weapons after the update when using the same setup. Both weapons are running the Deadly Accurate + Surgical blessings.

Against Crusher:
Bolt Pistol [full crit + full build]: 3481 (before) → 1742 (now)
Heavy Stubber [full crit + full build]: 3828 (before) → 1920 (now)

I really hope this is not an intentional nerf, I had a lot of fun using these weapons and they do not feel the same with the reduced damage profile. Thanks!

Steps to Reproduce (Required):

  1. Equip either a Bolt Pistol or Heavy Stubber.
  2. Ensure the weapon is running both Deadly Accurate and Surgical blessings.
  3. Enter the Psykhanium / Meat Grinder (Auric).
  4. Aim down sight till crit chance reaches 100%, shoot a Crusher (Carapace).
  5. Note the damage numbers and compare them to pre-patch baselines.

Bolt Pistol [no crit heatshot + no build]: 1743 (before) → 872 (now)

**Same pattern for Heavy Stubber
