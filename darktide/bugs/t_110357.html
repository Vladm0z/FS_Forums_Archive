Arbitrator "Press Once" Tag option is bugged

4 Posts • 83 Views
C
Cyl • 2025-07-03 19:57:09

Issue Type (Required):

Player Mechanics

Issue Description (Required):

Since the newest patch “Hotfix #70 (1.8.2)”, selecting the “Press Once” setting for the “Companion Target Tag” option no longer allows you to tag a target that was already tagged by someone else, regardless if they are also playing as an arbitrator, with or without a cyber-mastiff, if someone else tags an enemy you can no longer tag it to direct the cyber-mastiff to attack it.
For exemple a Veteran tags a monstrosity for the focus fire buff, or an ogryn tags it to see it because it’s a lights out map, you will thus need to wait until their tags wear out to be able to tag it and tell the cyber-mastiff to jump on it.
This bug happens when the “Press Once” setting is activated.

Steps to Reproduce (Required):

  1. Play as Arbitrator with the cyber-mastiff
  2. Go to the “Options” menu, go to the “Input” section and scroll to the bottom
  3. Then select and activate the “Press Once” setting for the “Companion Target Tag” option
  4. Join any match with other players and wait for them to tag any taggable enemy
  5. Try to tag the same enemy while they have already Tagged it; See that it is no longer possible
