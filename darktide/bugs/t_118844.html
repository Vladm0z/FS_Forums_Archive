Changing Class with outstanding join-request blocks application to a party

1 Posts • 27 Views

PHNX • 2026-02-22 11:42:35

Issue Type (Required):

Party Finder

Issue Description (Required):

A common situation is:

  1. Load into Morning Star
  2. Open Party Finder
  3. See party with one space for a role other than what I have loaded in as e.g. I’m vet but party already HAS vet
  4. Apply to the party thinking party-lead will credit me with the ability to change class after joining as I’m Havoc Forged / Exemplar / Vanguard, related to Chuck Norris etc.
  5. Often party leads won’t do this (because of the lack of ability to remove party-members pre-mission), and application status stays as “Applied” for a long-time
  6. So I change role to the class the party needs with the join-request still outstanding. It seems like my new class is shown to the party-lead BEFORE i’ve loaded in and they approve my outstanding request (from when I was vet) whilst I’m still seeing the loading screen and an error message is displayed saying something like “You can’t join this party as you are still loading”.
  7. Finish loading into MS, re-apply to the party, and application just says “Approved” but no pop-up appears to actually join the party and all subsequent applications repeat this bug. Essentially the party is now locked to applications without restarting the client (by which time the party will have found someone else).

This happens frequently and repeatably, so I thought I’d better report it. Could you please fix it, or better yet give party leads the ability to kick / vote kick from the party in the MS which would make them more likely to accept duplicate roles and just generally make the whole putting a crew together experience less hassle
