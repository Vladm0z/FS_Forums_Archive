Issue Description (Required):

Since patch v1.10.0 ALL textures do not load or stream in during missions (blurry). Affected missions: all/random - some missions load correct, some do not have any clear/loaded textures until end, some load after 10-15minutes.

I’m using a AMD Radeon RX 7900 XTX 24GB. Game is on a NVMe SSD - no problems before patch - tried different drivers (also newest driver 25.12.1), reinstalling, deleting settings files.

The game also crashes every time hitting the exit button which possibly prevents correct caching. → crash occurs while the game compiles/stores shaders before the .exe closes.

Possible workaround → deleting all or some of these cache files solves issue until next game start: \AppData\Roaming\Fatshark\Darktide - “shader_cache.hans, shader_library.pso_lib, state_stream_library.pso_lib”. Using “high preset” in addition without anything raised to extreme or mesh/decals modified ensures everything is also loaded faster.

Steps to Reproduce (Required):

  • Start game, play a mission = all textures blurry until end of mission or most time of mission.
  • Exiting the game is always a crash.
  • Deleting some cache files before start (see description) and using “high preset without anything raised to extreme or mesh/decals modified” resolves issue in most cases until next game start.

BLACK-TEMPLAR • 2025-12-12 07:37:18

After doing a little more research: the problem can’t be resolved on user side. There is a problem saving the “PSO” cache on exit since 1.10 - this has nothing to do with AMDs driver in particular, it’s more an engine/game bug on exiting but also in combination with AMD 7000+ series hardware.

Only way is the already mentioned method by deleting the pso cache before every game start.(Actually I didn’t try medium textures - it is unacceptable, sorry )

This also comes with some disadvantages - because of the missing cache the computer must load everything “live” - this can also cause map textures to load late - but this is only temporary. The longer the session or the faster the system the better it will run visually. I think this method won’t work good on low-end GPUs with less than 16GBs without impacting performance.
