Issue Description (Required):

Hello,

I would like to ask you to look into an issue with server ping.

Most Korean and Japanese players use the Hong Kong server because the player population on the Asia server is very small.

Before March of this year, the ping displayed in the options menu was the same as the ping experienced in-game. However, since the March patch, the in-game ping has been approximately 1.5 times higher than the ping shown in the options.

As shown in the screenshot, the Hong Kong server shows around 60 ms in the options menu. However, when I check the ping in-game using the ping measurement mode, it is around 90–100 ms.

Interestingly, after a mission ends and I return to Mourningstar, the ping goes back to normal.

In the past, around 60 ms was reasonably comfortable to play with. However, with the ping now reaching around 100 ms during missions, the game feels noticeably less responsive and less enjoyable to play.

As far as I understand, this issue is not limited to me and other players are experiencing it as well.

Could you please look into this issue?

Steps to Reproduce (Required):

  1. Check the ping value for the server you want to play on in the Mission Board options
  2. Measure your ping in-game
  3. Check if it’s similar to the ping value you checked in the options

[PC] Do You Use Mods? (Optional):

Yes, but I haven’t tried disabling them
