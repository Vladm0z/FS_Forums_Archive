Hardware Configuration:CPU: AMD Ryzen 7 9800X3D (8 Cores / 16 Threads / Zen 5 X3D Architecture) [913732.0.html]GPU: AMD Radeon RX 9070 XT (16GB VRAM / RDNA 4 Architecture) [azerty.nl]Issue Description:The Darktide Launcher’s automatic hardware detection matrix consistently fails to recognize modern component signatures upon boot. Because the Ryzen 7 9800X3D features a baseline integrated graphics processor on the CPU die, the launcher incorrectly flags the iGPU as the primary display device instead of routing directly to the dedicated discrete Radeon RX 9070 XT.This hardware misidentification triggers a cascade of broken configuration defaults upon every single application launch.The Key Points Impacting Performance:Worker Threads Override: The engine’s thread-mapping logic computes an outdated static formula, completely ignoring modern asymmetric 3D V-Cache topology. It continuously forces and snaps the CPU scheduler to 13 worker threads, resulting in severe context-switching bottlenecks and massive micro-stutters during high-intensity Auric Maelstrom horde rushes.Graphics Profile Resets: Because the hardware index defaults to the integrated chip, the launcher automatically resets customized user graphical settings back to low-end baseline values, corrupting the initialization shader cache and triggering crash-to-desktop errors.FSR & Frame Generation Locking: Due to the driver detection failure, the engine restricts access to native high-refresh features. It locks the game into legacy upscaling modes (like FSR 1.0 or Ultra Performance), completely graying out or disabling FSR 3 / Frame Generation toggles. Users are forced to manually rewrite these variables inside the local AppData strings just to access their hardware’s native feature set.Requested Permanent Fixes:Update the launcher’s display adapter scanning rules to recognize the Radeon RX 9070 XT and prioritize discrete dGPUs over CPU integrated graphics modules.Update the CPU auto-detection boundaries to stop forcing an asymmetric, odd thread count (13) on 8-core X3D hardware architecture.Introduce a toggle in the launcher settings menu to “Disable Automatic Hardware Scanning” so the game client is blocked from systematically wiping custom, manual edits inside the user_settings.config file.
