I start to suspect there is a link between using zealot’s stun grenades and causing all players to get disconnected from the game session..

This seems to happen in connection with some unknown factor(s) as it doesn’t always happen.

We all got disconnected when I dropped stun nade in a Havoc game with a lot of enemies present, this happened twice in that game. The server doesn’t seem to crash, as we were able to reconnect, but everyone got disconnected, at the exact same moment. I’m sure I saw error 2014 being displayed after I got kicked to the character selection screen.

The chance for this client disconnection seems to pretty high if you stun a lot of enemies in one explosion. I use mods, and I have both scoreboard mods and limited health-bar highlighting enabled on elites.

I wonder if this is down to the number of enemies getting damaged, stunned at the same time, especially with psyker inferno staff and stun nades applying all that damage ticks and statuses. I have no idea how this works client - server wise, on the network level, but could it be just number of updates between the server and clients resulting in some sort of de-sync issue?
