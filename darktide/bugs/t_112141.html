Issue Type (Required): Animation Issue Description (Required): Mk VI Power Sword’s Heavy 2 attack (diagonal uppercut, from left to right) has 2 different animations currently in use. The normal animation (chained from Light 1 or Heavy 1) shows the player character’s arm not fully rendered which looks really awkward in first person. This applies to the vast majority of existing upper body cosmetics on Veteran. However there is a second animation currently used that doesn’t have this issue with…

I’ve looked into this a bit more and it seems like there’re still many cosmetics that still have this issue even with the second version of the Heavy 2 attack. I suggest reducing this attack’s weapon FOV on top of aligning all versions of Heavy 2 with the animation that doesn’t have issues, so that it doesn’t come up again.

Steps to Reproduce (Required):

  1. Load into any 1st person game environment (meat grinder, live sessions)
  2. Perform Light 1 or Heavy 1, then perform Heavy 2. Hold the input fully to see the incomplete arm on bottom right.
  3. Perform Light 3 or Push Attack, then perform Heavy 2. Hold the input fully, and see that there’s no incomplete arm visible across the entire animation on screen. Then perform the attack without fully charging and see if it appears (some cosmetics do).
