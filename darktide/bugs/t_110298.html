Issue Type (Required):

UI & UX

Issue Description (Required):

At first, I wanted to put it to Gameplay Feedback one day, but it’s not clear if it’s even checked, and also I’ve been irritated by it so much lately (has been experimenting with new builds), so that I think now it’s an UI issue.

The problem is illustrated on the attached picture. I simply need to select another one of the mutually exclusive Blitzes in the Tree. Both builds would require exactly the same number of points, but the tree just won’t allow me to select another talent, I have to clear EVERYTHING after it, and only then I can switch them. It gets extremely frustrating when you need to do it often (when experimenting)

Solution: just allow to select another mutually exclusive talent in the case depicted on the picture, as it doesn’t result in an invalid “route” through the tree in any way. Even better: allow to deactivate ANY node on the tree, even in the middle of the “route” - and just don’t persist the result until a valid route is rebuilt; highlight invalid parts of the tree with red and display a warning if player wants to leave the screen before achieving a valid build.

Steps to Reproduce (Required):

  1. Build any full Ogryn build that goes from top to bottom of the tree.
  2. Try to change the type of Blitz it has to any other option, without resetting the whole nodes of the tree beneath it.
