Issue Type (Required):

Character Customization

Issue Description (Required):

(I wanted to put this under Exploits, due to giving you the benefits of the smallest possible hitbox with the best possible vision. And it’s definitely NOT a visual bug since it directly affects gameplay mechanics.)

I always make my human-characters the tallest possible height, and ever since the Hive Scum release, something has nagged me since the very start after playing for a while; why am I tilting UP all the time to hit with my melee and ranged weapons? I know what the height between the player and the regular hordes should be (among other units), so it’s not a matter of confusion here.

HIVE SCUM has a customization bug where the vision and height are reversed; the Tallest height has the vision of the smallest height; and the reverse rings true for doing the smallest height.

Steps to Reproduce (Required):

Part 1: (Test the height)

  1. Make any of the 4 original humans at the tallest height (Veteran/Zealot/Psyker/Arbitrator).
  2. Stand next to an NPC to confirm height correction (pref. same as video, close to Psykhanium)
  3. Go to Grinder (use the Mauler as a point of reference for eye-level, plus any of the horde units)
  4. Get up close and note the vision height / eye-level.
  5. This produces the correct height + vision as expected between all of them.

Part 2: (Hive Scum, Tallest)

  1. Make a HIVE SCUM at the tallest height.
  2. Stand next to an NPC to confirm height correction (pref. same as video, close to Psykhanium)
  3. Go to Grinder, use same point of reference for vision height / eye-level.
  4. Get up close and note the vision height / eye-level.

Part 3:

  1. Make a HIVE SCUM at the shortest height.
    Repeat steps 2-3-4 from the previous parts.

Tallest height: shortest vision
Smallest height: tallest vision
