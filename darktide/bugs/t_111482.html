Veteran Perk - Deadshot Active For Melee Weapon

1 Posts • 37 Views

Issue Type (Required):

Talents

Issue Description (Required):

The tooltip text for Deadshot,

“+25% Critical Chance & +60% Sway Reduction while using your Ranged Weapon’s alternate fire, but lose 0.75 Stamina per second and an additional 0.1 per shot.”

Now, obviously this is a tradeoff for ranged weapons, because you can only get the benefits while actively using a ranged weapon in a session.

However, while wielding a melee weapon, where you don’t get the benefits, you still experience the penalty of having your stamina drained while blocking.

If this isn’t a bug, then it’s simply an egregious design decision and makes the talent so much more trouble than it’s actually worth.

If needed for recreation, this is the exact build I was using at the time.

Veteran build for Warhammer 40k: Darktide, using the Antax Mk V Combat Axe and Accatran Mk IX Combat Shotgun. Created by thenonman.

Steps to Reproduce (Required):

  1. Play a vet.
  2. Reach the level necessary to be able to choose the Deadshot talent.
  3. Equip the Accatran combat shotgun and the antax combat axe (my load out when experiencing this).
  4. Play a game, watch as your stamina drains by itself while blocking with the axe.
