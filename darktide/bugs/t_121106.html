Issue Type (Required):

Visual

Issue Description (Required):

When using one of the chain weapons, the VFX of the exhaust smoke from using the special function sometimes gets bugged and stays active for the entire mission, even while using the ranged weapon which is basically game breaking for any precision weapon and annoying for everything else. This bug exists for quite some time now but definitely wasn’t there on release of the game. This was introduced with a patch some time ago (see below).

There are some important notes:

  • It seems to be not possible to reproduce it in the Psykhanium, only happens in missions
  • It seems to be triggered either if the player gets disabled while the special of the chain weapon is active, or if a target getting sawed gets killed by another player
  • It can happen on all chain weapons

One theory I have worth investigating is that this bug happened to me first sometime after the Arbitrator class was released. Prior to the hotfix #69 (1.8.1), one cosmetic of the cyber mastiff was causing troubles due to it’s smoke emitting effect, which was temporary disabled with said patch. In the hotfix #71 (1.8.3), the smoke effects were enabled again on the cyber mastiff skin. It could be possible that whatever was changed in #71 on the mastiff smoke effect caused the chain weapon effect to bug out.

Please take this bug serious as it ruins the chain weapons and it’s like having a smoke grenade stuck in the face for the entire mission.

Steps to Reproduce (Required):

  1. Use a chain weapon and play a mission (not Psykhanium and no hosted session)
  2. Activate special rev function and try getting disabled by different specialists and possibly have another player kill enemies that are currently being “sawed” with the special rev function
  3. See the smoke VFX never disappear, even when switching weapon

[PC] Do You Use Mods? (Optional):

Yes, and I’ve tried disabling them

Reproduction Rate (Required):

Unusual (<25%)

Platform (Required):

PC - Steam
