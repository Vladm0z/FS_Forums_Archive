Issue Type (Required):

Talents

Issue Description (Required):

As the title says, landing a critical hit with the ‘Power Redistribution Uplink’ node gives you the ‘Entropic Transfer’ buff. Now, I’m not 100% certain if its a UI or gameplay issue but something’s gone wrong.
I’ve done some testing, and can confirm it happens in-mission and in the Psykhanium, with presumably any melee or ranged weapon on any enemy.

Steps to Reproduce (Required):

  1. Go into any game instance with the talent ‘Power Redistribution Uplink’ equipped.
  2. Critically hit any enemy.
  3. Press ‘TAB’ (or controller equivalent) and see the buff for ‘Entropic Transfer’ being applied instead of the initial talent.

Reproduction Rate (Required):

Constant (100%)

Platform (Required):

PC - Steam
