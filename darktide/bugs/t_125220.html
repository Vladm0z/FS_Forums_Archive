It requires all stimm talent points to be allocated for the Penance to work (for “at leaat 50% viscosity”)

I couldn’t believe this as it would mean the penance text is entirely wrong. That instead of “at least 50%” it should say “at 100%”, in which case lots of people would definitely have run into this. So I ran some experiments and figured what the bug is.

At 100% viscosity (as suggested is the requirement), this tree still doesn’t result in any penance progress:

image1920×874 514 KB

I’ve highlighted why. You have to have at least one stimm talent point in that upper left section. That’s the toughness restoration section. This is a bug because I am running the Chem Fortified class talent which replenishes 50% toughness on stimm (see screenshot and reproduction steps above). But, that 50% doesn’t count towards the penance unless you have at least one point in that toughness section of the stimm talnet tree. If you do, then that 50% toughness talent is counted. Which is just broken behavior.

My guess is there is a bug in the code that makes it ignore toughness gen if no stimm talent points are in that toughness section even though Hive Scum has a class talent that restores toughness on stimm.

Of course, none of this explains how I magically got 97 points of toughness a couple of days ago (though, I’m wondering if it was because some other Hive Scum was running Stimm Supply and their ability caused me to regen toughness even though using your own ability doesn’t count toward the penance – another bug?).
