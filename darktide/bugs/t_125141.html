kuli • 2026-08-24 20:22:44

Within the terminology of the guide, “Standard Melee” refers to how the attack deals damage to toughness.

image608×115 17.1 KB

This does not necessarily imply that the attack in question is a melee attack like any other (there is a dedicated guide section about ‘the usual’ melee attack types). In fact, the mutant grab, as others have indicated, is somewhat unique because it has its own logic to check for colliding players (via sphere overlap query).

Patch 1.12.4 made a couple changes under the hood (mainly to allow dodge linger time to work on several grab attacks). AFAIK, the current state where slide to dodge grabs does not work is not intended and is going to be addressed.
