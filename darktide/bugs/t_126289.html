Veteran talent “Always Prepared” interacting weirdly with “Lock and Load”

1 Posts • 33 Views
B
Bricksolr • 2026-10-03 12:28:59

Issue Type (Required):

Talents

Issue Description (Required):

If you take the Veteran talent “Lock and load” (L&L), “Always Prepared” (AP) will only reload bullets up the guns base mag size.

Steps to Reproduce (Required):

Example:

Gun: Huntsman Shotgun
Base mag size: 6
Mag size with L&L: 8

If you have the maximum amount of stacks, AP should restore 3 bullets to the mag (8 * 33.3% rounded up)

If you active AP with 0,1,2, or 3 bullets in the mag, you get the full 3 bullets.

If you activate AP with 4 or 5 bullets in the mag, you will get shorted bullets and only go up to 6.

If you activate AP with 6 or 7 bullets, you receive a single bullet.

I am unsure if this bug exists for all ranged weapons, but I have recreated this issue with Agripinaa stub revolver as well.
