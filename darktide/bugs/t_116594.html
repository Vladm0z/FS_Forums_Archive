Not sure if this will help but it might be worth a BIOS update and manually setting your GPUs PCIe x16 slot to PCIe 4.0 in BIOS

There’s two version of the B650: B650 and B650E.

The regular B650 only supports a few lanes of PCIe 5.0 for an NVMe drive. B650E added PCIe 5.0 for the x16 slot.

Gigabyte has the auto setting default to 5.0 on the x16 slot despite the chipset not supporting it which may work but can absolutely cause signal integrity issues if the PCB wasn’t designed with it in mind.

You can check what your GPU is using in adrenaline in the System tab by clicking the Hardware Details dropdown under your 9070 XT. Before I changed it it was defaulting to 5.0 x8. Now it’s 4.0 x16 (which is the same speed but hopefully more stable):
