  • If it matches, it stays highlighted
  • If it doesn’t, we show the server version instead and the highlight disappears

This prevents the UI from showing the wrong loadout. We understand this change may present some confusion, and we’ll be working on making this clearer in a later update.

FatsharkJuliaCommunity Support • 2025-09-25 07:41:22

After speaking with the developer handling this, I’ve received this update:

  • There are situations where the selected loadout preset doesn’t have a title and/or some emotes equipped. If that is the case, the loadout will generate an error while saving to the backend. This will cause the preset to not be selected, and players should take a look at their cosmetics slots.
  • We’re investigating why the slots can become unequipped, which is an unintended behaviour.

We’ll better highlight and alert the player for these slot issues in a future patch.
