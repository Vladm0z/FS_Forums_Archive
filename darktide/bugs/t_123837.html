Issue Type (Required):

Missions

Issue Description (Required):

On the Dark Communion mission, there’s a mid event where you get locked in a large room and enemies drop down from the ceiling. The main doorway is supposed to open after the voice lines from the Admontion cultists play and a monstrosity spawns.

For whatever reason, the doors are opening before the monstrosity spawns sometimes. I’ve been playing Auric Maelstrom with weakened mostrosity spawns, so it could be that a random spawn is triggering the door to open.

If players leave that area too early, the mission can be soft-locked until they return to the event area to trigger the monstrosity spawn. If you go to the elevator, you won’t be able to advance the mission until after this event has finished.

This has happened to me twice in the past week, so it seems reproduceable.

Steps to Reproduce (Required):

  1. Play the Dark Communion mission on Auric Maelstrom I-II-V-E-G.
  2. Doorway opens before the event monstrosity spawns.
  3. Leave the event area and go to the elevator. You won’t be able to push the button to activate the elevator.
  4. Return to the event area and fight enemies until the event monstrosity spawns.
  5. Kill the monstrosity. You should now be able to activate the elevator.

Mission Name (Optional):

Dark Communion

[PC] Do You Use Mods? (Optional):

Yes, but I haven’t tried disabling them

Reproduction Rate (Required):

Common (<50%)

Platform (Required):

PC - Steam

For what it’s worth, the reason for this is that the trigger to the doors opening is a monstrosity dying. So when a weakened monster spawns in a special wave and you kill it there, the door opens immediately rather than with the full monster spawned at the end of the event.
