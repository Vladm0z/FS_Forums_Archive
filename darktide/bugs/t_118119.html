Issue Type (Required):

Penances

Issue Description (Required):

Multiple difficulty-based penances reference removed or outdated difficulty names and do not fully align with the current difficulty structure, where Auric is its own difficulty accessed via the Auric Mission Board.

This issue affects all difficulty-tiered penances, not only Prove Your Worth.

Observed issues:

  • Sedition Threat is still referenced in penances, despite Sedition having been removed.

  • Auric is treated inconsistently:

    • Auric is now its own difficulty (via the Auric Mission Board),
    • but difficulty-tiered penances do not consistently reflect this structure.

  • Damnation is treated as the highest difficulty tier in penance ladders.

  • Some penances still use wording that reflects older difficulty assumptions, leading to mismatches between penance text and current gameplay.

Examples:

  • Prove Your Worth (1) requires:

    “Complete 1 mission on Sedition Threat or higher.”

  • Higher tiers culminate in Damnation, even though Auric missions represent the current highest difficulty content.

Expected result

  • Penances should not reference removed difficulties.

  • Difficulty-based penances should reflect the current difficulty structure, where:

    • Sedition is removed
    • Auric exists as a distinct difficulty

  • Penance tier progression should clearly and consistently account for Auric where appropriate, or explicitly define whether Auric is excluded by design.

Actual result

  • Penances reference removed difficulties (Sedition).
  • Difficulty tier progression does not fully align with the current Auric-based structure.
  • Some penance descriptions are misleading or outdated.

Impact

  • Causes confusion about valid progression paths.
  • Makes it unclear how Auric fits into difficulty-based penance completion.
  • Creates inconsistency between penance text and the mission selection system.

Additional notes

This appears to be legacy penance data that was not fully updated after:

  • Removal of Sedition
  • Introduction of Auric as a distinct difficulty accessed via the Auric Mission Board

Steps to Reproduce (Required):

  1. Open Penances

  2. Navigate to any difficulty-tiered penance chain (e.g. Prove Your Worth, mission completion penances)

  3. Review the requirements across tiers

  4. Observe:

    • Sedition is referenced
    • Auric is not listed as a tier
    • Damnation is treated as the final tier
    • Auric not clearly integrated into the tier progression
    • Auric Heresy / Auric Damnation terminology is still used
