Issue Type (Required):

UI & UX

Issue Description (Required):

Several bound inputs do not consistently register when their assigned buttons are pressed. The input event simply fails to trigger, despite the keybind being correctly set and functional in other contexts.

Affected Inputs

The issue has been observed with the following actions:

  • Tag
  • Open Com Wheel
  • Open Tactical Overlay
  • Activate Blitz

Pressing the assigned key/button produces no in-game response, even though:

  • The input is correctly bound in the settings
  • The same physical key works for other actions
  • Rebinding does not reliably resolve the issue

Expected Result

The action should trigger immediately when the assigned input is pressed.

Actual Result

The input is sometimes ignored entirely — no action is performed, and no feedback is given.

Additional Notes

  • This does not appear to be a hardware issue

  • The problem persists across rebinds and restarts

  • It feels like an input state or priority conflict, possibly related to:

    • UI layers
    • Action gating
    • Input buffering being dropped under load

  • Most noticeable during combat or high-input situations
    *May be related to recent changes in input handling or UI layering.

Workarounds

  • Restarting the game sometimes temporarily resolves the issue
  • Rebinding the action may work briefly, but the issue can return

Steps to Reproduce (Required):

  1. Launch the game

  2. Ensure one or more of the affected actions are bound

  3. Enter a mission (issue most noticeable during active gameplay)

  4. Press the bound key repeatedly for:

    • Tag / Com Wheel / Tactical Overlay / Activate Blitz

  5. Observe that the action does not trigger
