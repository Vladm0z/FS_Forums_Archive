Issue Description (Required):

I began having this issue on 14/03/2026. During normal gameplay, I started noticing my character animations lagging, even though my system performance and connection remained stable. Continuous play only worsened the bug to the point where attacks were delayed, gunshots didn’t register, parries became impossible, abilities wouldn’t activate, and guns took twice as long to reload. Squad Player Models, Enemy Models, and Environment all perform within expectations. This is present in all game modes, except the meat grinder. Two updates to the game have since been released, and the issue has persisted through the patches. Here is a long-form video of the issue in action (https://youtu.be/vzd4ovptBMc).

A temporary fix was found: when couching, moving, and alternate fire are used simultaneously, the animations play normally. This only works temporarily before the issue returns, and the action needs to be repeated.

There was a microsoft update a while back, specifically when they introduced 25h2, that caused issues with shader caches across a multitude of games, this could be related. I had similar issues with stuttering and action delay. Here’s a couple steps to try that I don’t see listed above.

  1. On your video card control panel, disable shader cache
  2. Run Disk Cleanup for the drive Darktide is installed on
  3. Only select DirectX Shader Cache and clean up system. This will completely clear the shader cache on that drive.
  4. Restart computer
  5. On video card control panel, set shader cache back to default or previous setting
  6. profit? At least worked for me. Darktide will take a while to launch the next time around as it will have to rebuild the shader cache fresh.
