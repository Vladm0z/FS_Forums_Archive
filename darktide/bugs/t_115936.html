Issue Description (Required):

When using the Stim that the Hive Scum has access to, there is a seemingly random chance that it will break the character animations and inputs. For example, after using the stim and the effect of it going away, the following things will happen: you are unable to attack and doing so will result in your character charging up an attack and instead doing the push animation, you will automatically start using the stim again after it cools down, you will be unable to sprint.

Steps to Reproduce (Required):

  1. Use the Hive Scum exclusive Stim.
  2. Wait for its effects to go away.
  3. The bug will have a seemingly high chance to occur.

Reproduction Rate (Required):

Often (<75%)

Platform (Required):
