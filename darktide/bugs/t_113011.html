Issue Description (Required):

Deciding to post this just in case it wasn’t an intentional change.

Going through recent console logs reveals that the culling implementation is using a slower instruction set than before. It could be that it’s actually properly choosing what instruction set to use based on detected features but (like the launcher reading system memory as 0 if you don’t have an Intel cpu or the game logs not detecting if HAGS is on) even that’s not correct.

Console logs report my CPU only supporting up to SSE 4.1:

01:22:09.850 [Application] --- CPU
CPU: AMD Ryzen 9 7900X 12-Core Processor            
Vendor: AuthenticAMD
Logical processors: 24
Family: 10:15, Model: 6:1
Type: 0, Stepping: 2
Features: SSE SSE2 SSE3 SSSE3 SSE4.1

While the 7900X supports all the way up to AVX-512

Pre-update logs would show the culling use AVX2 despite the game not detecting it properly:

22:17:47.762 [MOC] Using moc implementation AVX2

Now they report it as SSE 4.1

01:22:52.273 [MOC] Using moc implementation SSE41

I guess it could be an intentional change but that seems like an odd thing to do given how one of the frequent complaints about the game is performance. Especially considering console releases as both console offerings have Ryzen 3000 equivalent CPUs and should support AVX2.

I won’t ask for an update to AVX-512 or anything considering

the launcher reading system memory as 0 if you don’t have an Intel cpu

the dev systems are Intel I’m sure and Intel would rather literally fuse AVX-512 support off of their P-cores than add it to their E-cores but clarification would be neat

Steps to Reproduce (Required):

  1. Start the game post-1.9.0
  2. You are now using SSE 4.1 and can check the logs to verify (oddly enough MOC only kicks in after choosing a character and joining a mourningstar instance so you’re better off just searching for it)
