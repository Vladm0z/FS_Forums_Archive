Issue Description (Required):

There’s an annoying issue with hit registration using both ranged and melee weapons. Enemies are hit and there’s visual feedback but the game doesn’t register the hit so enemies don’t take any damage and no hit markers appear. The issue is especially noticeable with semi-auto ranged weapons. Sometimes specialists completely ignore melee hits, don’t get staggered and continue running towards their target.

Steps to Reproduce (Required):

  1. Use semi-auto ranged weapons (e.g. Vigilant Autoguns) to easier reproduce the issue
  2. Shoot enemies
  3. The game plays an animation for a hit enemy
  4. No hit markers and damage
