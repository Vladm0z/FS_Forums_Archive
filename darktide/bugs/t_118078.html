Commissary UI does not reset scroll position when switching categories or classes

Issue Type (Required):

Character Customisation

Issue Description (Required):

Hello,

I’d like to report a UI issue in the Commissary where the scroll position is not reset when switching between categories and/or classes.

Issue summary:
The cosmetic and weapon item grids reuse the previous scroll position instead of resetting to the top when switching categories or classes. This causes item lists to open partway down instead of at the beginning.

Expected behavior:
Each category (cosmetic slot or weapon type) should reset its scroll position to the top when selected.

Actual behavior:
The UI appears to reuse a shared scroll offset across different categories and/or classes.

Additional notes:

  • The issue is most noticeable when the target category has more items than the previously selected one.
  • Veteran leg cosmetics make the issue particularly visible due to a longer item list.
  • Temporarily resolved by switching to a different category first or reopening the Commissary.
  • This appears to be a general UI scroll state persistence issue rather than class-specific behavior.

Thank you for your time.

Steps to Reproduce (Required):

Cases where this occurs:

Case 1 – Cosmetics (Legs):

  1. Open the Commissary.
  2. Select any class.
  3. Open Legs in the cosmetic menu.
  4. Switch class (notably to Veteran).

Result:
The leg cosmetics list starts partway down instead of at the top.

Case 2 – Weapons (Melee → Ranged):

  1. Open the Commissary.
  2. Select Melee Weapons.
  3. Switch to Ranged Weapons.
