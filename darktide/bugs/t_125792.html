Dizzy721Regular • 2026-09-22 14:54:03

The reason it isn’t is because the 375 damage value includes the Ogryn’s base aura which is 7.5% damage on heavies. All sources of +Damage are added together before being multiplied against the base damage.

If you set your tree to this, you have no +Damage to melee attacks by default, since Ogryn’s Aura is no longer his base 7.5% damage on Heavies. You will do 348 damage which makes sense: 297×1.3×1.00×.9012.

Add in Heavyweight, you will do 453 damage: 297×1.3×1.3×.9012

Remove Heavyweight and proc Payback Time, you will do 401 damage which is 15%. 297×1.3×1.15×.9012.

Add in both, you will do 505 damage: 297×1.3×1.45×.9012, with the 1.45 value derived from adding 30% Heavyweight damage and 15% Payback Time together.

For Crunch, the equation for your setup would look like this:
Just 5% rending, no Crunch:
297×1.3×1.075×.9512 = 395
W/ Crunch fully charged:
297×1.3×1.375×.9512 = 505

If you change tree to this you can isolate and observe the 30% increase happening between having Crunch selected or not. 368 Damage without Crunch, 478 with it, a 30% increase.

What you’re anticipating is that each instance of +damage would be added to the multiplication chain but that’s not how it’s set up (for good reason too I think), so e.g.: 297×1.3×1.075×1.30×.9512 would get you the 513.5 number you calculated but it’s just not how the game does it.
