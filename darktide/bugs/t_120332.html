I’ve encountered the same issue. The problem occurs when trying to select a different server under the ‘Matchmaking Server Location’ drop-down list at the Expeditions terminal and only when using a controller (using a mouse and keyboard is fine).

I’ve found the issue to be persistent on Xbox console, PC Game Pass and Steam.

You can open the drop-down list on your first attempt but it looks like your controller is scrolling through the server list while at the same time also moving around the Grid Points selection. When confirming your server choice (by pressing A on an Xbox controller) you seem to also be selecting the mission start option as well and you end up starting a mission instead of selecting a new server.

On subsequent attempts to access the drop-down list, you can open the server list for a split second before it will start a mission and closes down the window.

My current work-around:

  • On Xbox console, I have to go to the regular Mission Terminal and change my server there before heading back to the Expeditions terminal
  • On PC Game Pass and Steam, I have to switch to mouse & keyboard to change the server, close the window and then I can go back to controller.
