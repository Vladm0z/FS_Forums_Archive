Issue Type (Required):

Issue Description (Required):

After playing the game for a while, maps start to have major graphical bugs. The visual errors present themselves in two ways:

  1. Visual errors resulting in large, low-poly structures obscuring parts of the map. The visual bugs are always the same specific structures, often resembling large walls, decorative structures, or uninterruptable doors.
  2. Visual errors resulting in rapid flickering dark rectangles appearing on the screen while moving or looking around in certain areas.

The quickest way to see this visual bug is on Clandestium Gloriana, where, once the errors have begun occurring, you can see the vertical shuttle after the first event bugged out, provides evidence of both errors. The first error is visible as early as the shuttle tracks after the first event. The shuttle and track, which is usually hidden and replaced with the appearance of a the long path that the shuttle zooms on to the next area, is visible alongside the intended visuals for the area. Entering the travel shuttle will result in the second error, being the flickering rectangles. However, this error is present on several maps, not just Gloriana, Gloriana is just the map that I can most quickly come across this bug.

I’ve provided a few examples of this bug occurring on maps where it is particularly noticeable, including the most accessible errors on Gloriana (notice in the images of the flickering rectangles, the rate of my teammate’s health decreasing, as an indicator for how quickly and frantically the flickering is).

I’ve also provided a few console logs. I’ve analyzed the smallest console log I’ve provided with Claude AI, which seems to be convinced that this error is a result of memory leaking, specifically pointing to “D3D12_RESOURCE Render Target was not released”, which seems to result in these improper textures not being removed or hidden.

I’ve tried lowering texture quality, lowering mesh render distance, installing and trying various NVIDIA drivers, disabling/enabling various mods, validating files, altering settings.ini and user_settings.config, but nothing has resulted in a permanent solution.
