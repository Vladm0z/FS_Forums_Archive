Hey all! We’re seeing reports about the progress for the Heretical Artifacts event progress not appearing to update correctly.

Please rest assured that everything is tracking correctly.

For events, the progress tracker is normally updated upon end of round. However, as this event requires pledging in the Mourningstar hub, it then requires re-entering the hub for the progress to reflect in the UI.

We appreciate it’s not ideal and a little confusing! Hopefully this eases any concerns!
