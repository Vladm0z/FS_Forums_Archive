FatsharkLevCommunity Support • 2026-07-27 10:14:15

There seems to be a conflict and some muddle between your 5080 GPU and AMD Radeon 610M.

Firstly, please try changing your adapter_index setting in your user_settings.config file. This was suggested in our earlier troubleshooting but a clean reinstall would undo this change.

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate toAppData\Roaming\Fatshark\Darktide
  4. Open your user_settings.config file
  5. Find the setting named adapter_index
  6. Change this setting value to adapter_index = 1
    (If the adapter_index value is already set to 1, please try changing this to 0 instead)
  7. Save your user_settings.config file
  8. Launch Darktide as usual
