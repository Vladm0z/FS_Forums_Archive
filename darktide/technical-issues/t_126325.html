Hello everyone;

Issue: Recurring problems with newer Nvidia drivers.

Unfortunately, for me (and evidently for several others too), only certain versions of Nvidia drivers are compatible. I would like to ask the developers to look into this and fix the problem for the future, or at least provide clear guidance on how to prevent it for the community. And as always, the problem is properly much bigger than me and some other. Many do not change their drivers often or play the game regularly. I know from my near community.

They don’t report the issues, let alone test it out, and are quick to blame Nvidia. What I’m trying to say is, please take this post seriously. It’s meant as genuine help, Thank you.

I have noticed the following over the last few years. These observations have been confirmed on multiple occasions and are not attributable to generic errors. I would like to help the developers find a lead with this list. As I come from a software development background, I know how unsatisfactory superficial error messages can be, so here are more details:

Darktide Latest (Steam)

The error manifests itself as follows in detail.

  • The launcher starts (Launcher.exe Windows process) without rendering a window. The process remains active indefinitely. Presumably, it is waiting for some kind of response? A forced termination is required.

  • If Darktide.exe is launched directly, the game begins the loading process and the intro video plays smoothly, including sound. After the title screen (Space bar), it closes with the message “Backend error, error signing in”. Presumably because EAC wasn’t loaded?

  • No mods are installed. No mod manager, no Reshade or similar.

This issue occurs with various drivers on Windows 11

  • 610.88-whql

  • 617.14-whql

  • Others not noted over time

If I revert to 591.74-whql with NO other changes, the game loads and runs perfectly fine with no issues at all.

Furthermore, all other games tested load and run without issues. This includes, amongst others, all PC platforms

  • The Witcher 3 Remastered – GOG

  • Baldur’s Gate 3 – GOG

  • Halo Campaign Evolved – Xbox PC

  • Forza Horizon 6 – Xbox PC

  • Cities: Skylines 2 – Xbox PC

  • Total War: Warhammer 2 – Steam

  • Onimusha – Steam

  • Valheim – Steam

  • Tempest Rising – Steam

…

There are more games; none of them has any issues. As you see there is a diversity in the game. And I would like to play some of the latest ones which comes with the need of somewhat up-to-date drivers.

The same was true for a long time in 2025, when I had to keep reverting to version 566.36-whql in order to play DT. At some point, a newer version (591.74-whql) started working by chance. I’ve stuck with that one ever since.

In summary: Changing the driver version is sufficient as a workaround to be able to play the game. No other changes were made. However, other changes have no effect either, provided the ‘correct’ Nvidia driver version is installed.

I think it’s fair to say there’s something peculiar about the implementation of Nvidia drivers in Darktide, and that Darktide cannot simply shift the blame onto the drivers alone. Don’t misunderstand please, I want to help fix this.

If you have any constructive queries or details I’ve overlooked, please do let me know. I’m happy to help find a solution.

At the very least, we should be able to identify the cause so that we know how to deal with it.

Thanks again in advance.
PS. I’m not native English so keep that in mind
