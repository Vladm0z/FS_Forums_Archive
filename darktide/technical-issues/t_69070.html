I may have a bandaid to make this playable with FSR till they fix DLSS. Try turning on DSR on your Nvidia control panel and select 1 resolution higher than the one you normally play on. If you play on 1080p select 1440p, if you are on 1440p select 4k etc. Smoothness should be like 65-80% but that’s personal preference.
Then launch the game with FSR 2 on Balanced and select your higher resolution that now should be available in-game or in the launcher. Quality will be slightly worse, performance slightly worse but playable. You should mind your temps though, since DSR tends to up the GPU temp by like 8-15 C. Should work fine though if you are below your GPU threshold.
I’m really looking forward to a fix for this though, since it sucks…

Fixes I have tried include:

  1. Deleting all of the shader cache stored in %APPDATA%/Roaming/Fatshark/Darktide

I had the same issue but was able to fix it by:

  1. Disable steam cloud backup
  2. Delete Fatshark folder in appdata
  3. delete all data in steamapps/common/darktide
  4. verify game (this triggers a full install)
