FatsharkLevCommunity Support • 2026-08-24 10:17:27

Sorry to hear this @silverplushie

If you haven’t already done so, please try the following:

  • Uninstall your current GPU drivers using a dedicated driver removal tool e.g. DDU (Display Driver Uninstaller) and then reinstall latest clean drivers
  • Disable Steam Cloud Save, then delete AppData and Verify Integrify of Game Files:

Step 1: Disable Steam Cloud Saving
If Steam Cloud saving is enabled for Darktide, this may automatically restore the AppData and consequently cause the issue to resurface.

  1. Navigate to your Steam library
  2. Right-click Darktide
  3. Select ‘Properties’
  4. On the ‘General’ tab, scroll down to ‘Steam Cloud’
  5. Disable ‘Keep game saves in the Steam Cloud for Warhammer 40,000: Darktide’

Step 2: Delete AppData
NOTE: By deleting your AppData, operative loadouts and custom keybindings will be reset. You may wish to make a back-up of the directory in the event deleting your AppData does not work to resolve the issue.

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to: AppData\Roaming\Fatshark
  4. Delete the entire ‘Darktide’ directory

Step 3: Verify Integrity of Game Files
You will then need to use the ‘Verify Integrity of Game Files’ option, which is accessible via the Steam client and will ensure the installation is complete.

  1. Right-click Darktide in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify Integrity of Game Files’ button
  5. When complete, close and reopen Steam

Please let me know how you get on.

I found the solution that worked for me:

NOTE: My game was in an UNMODDED state as all traces of mods were removed when previously performing a clean install.

Here is what solved this for me;

  • 1: I added the exclusions screenshotted in the post above this one. My best guess is that it was the folder exceptions that fixed it, however adding all of them shouldn’t hurt anything.

  • 2: I manually deleted all files related to Darktide in my AppData. I did NOT reinstall the game at this point as the game had already been reinstalled several times while troubleshooting. You may need to do this if you haven’t already.

  • 3: I verified my game’s files via steam. If you are not a Steam user, you will have to figure out how to verify your game files on whatever platform that you’re using.

  • 4: With all of that done, the game launched successfully. Now to fix all of my settings and mods -.-

My best guess is that something somewhere in the game’s files was being messed with despite the myriad of exclusions and exceptions that I added prior to this post being made. I remade the exclusions and exceptions as a sanity check and after verifying my game files again to repair anything that might have been damaged / missing, the game now launches.

I have ZERO idea as to why the game went from working without issue to crashing on launch when nothing about my system was changed (no driver updates, no windows updates, no major changes to my installed software), but I’m just gonna blame Windows 11.

Hopefully this will help someone in the future!
