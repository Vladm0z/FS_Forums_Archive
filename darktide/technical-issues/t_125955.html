FatsharkLevCommunity Support • 2026-09-30 17:22:04

Ah I see, no problem!

As another person is on the same network without issue, this points towards something specific to your PC; or a per-device rule on the router possibly.

Some things that we can check specifically for your machine:

  • System clock/date
    If it’s wrong, TLS certificate checks fail exactly like this while normal browsing keeps working
  • If you have a VPN installed
    Even if disconnected, a VPN can leave a virtual network adapter or routing rule active that only affects some connection types. If you have a VPN, could you try fully uninstalling/disabling it and retrying?
  • Antivirus/Firewall with HTTPS scanning
    Norton, McAfee, Avast, Kaspersky, ESET, Bitdefender and others have an SSL/web shield feature that intercepts secure connections. Can you please try temporarily disabling and then signing in
  • Router per-device rules
    Parental controls or device-specific QoS/MAC filtering on the router can single out one device even on a shared connection. It may be worth checking your router admin page for any rules that could be tied to your PC
  • IPv6
    If your PC uses IPv6 while the other device uses IPv4 (or vice versa), and the network’s IPv6 route is the broken one, you could try toggling IPv6 off on the adapter as a test. To do so:
  1. Press Windows Key + R to open the Run menu
  2. Type ncpa.cpl and press ‘Enter’
  3. Right-click your active network adapter (e.g. Wi-Fi or Ethernet) and select ‘Properties’
  4. In the list, uncheck ‘Internet Protocol Version 6 (TCP/IPv6)’
  5. Click ‘OK’ and save changes
  6. Then try to launch and sign-in to Darktide

Please let me know how things go!
