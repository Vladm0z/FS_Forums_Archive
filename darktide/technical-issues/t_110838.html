gpkgpk • 2025-07-15 16:41:50

The folder should be there:

%appdata%\Fatshark\Darktide

Paste it in a Run box (Win+R) or Explorer Address bar (Win+E)

The %appdata% is an Environment Variable, with the appended “\Fatshark\Darktide” it resolves to:

C:\Users\YOUR_USERNAME\AppData\Roaming\Fatshark\Darktide

The darktide_launcher.log file exist there, and the game logs are in the console_logs sub-folder.
