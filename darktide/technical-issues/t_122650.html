PSA: Skitarii Name Validation Rules

20 Posts • 1879 Views
F
FatsharkLevCommunity Support • 2026-06-23 15:18:09

When naming your Skitarii operatives, our validation rules have been updated with the following:

  • Must start with a letter
  • Maximum of 3 digits in the name
  • Cannot start or end with a hyphen
  • Cannot include spaces or special characters
  • Hyphens are allowed between alphanumeric characters

We look forward to seeing some fun names!

If you experience a name validation issue we can review and add names to the allow-list. Please submit a support ticket to us and we will assist, here:

https://support.fatshark.se/hc/en-us/requests/new

Thank you!
