Just a general side note for ppl and OP:

Many good, mid to high end motherboards will have a USB flashback recovery that can be booted to re-flash the BIOS if needed, some work without a CPU too (so you can add later new CPU models). Other mobos will have a dual bios (Gigabyte).

If you have a bit of $ a UPS is a very worthwhile investment for peace of mind, even when flashing BIOSes.

Both Zoro and Meat chimed in with good suggestions adding to Lev’s, the Windows Event viewer sometimes has additional info that can point to the culprits.

The game crash dump or Windows dump files (*.DMP w/ WinDbg.exe)if hard crash/BSOD can often give valuable info too, even 3rd party sites like Dell have started including instructions

dell.com

How to Use Windows Debugger to Troubleshoot Bluescreens | Dell Canada

Google for more info.
