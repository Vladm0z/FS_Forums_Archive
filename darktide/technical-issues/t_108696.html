For this kind of issue, I recommend performing a clean reinstall of the game.
If you’re using any mods, it’s best to delete the entire game folder after uninstalling it, as leftover mod files can cause problems.
Based on the symptoms, it’s likely that the map or textures are either not loading properly or loading extremely slowly.
Just to be safe, right-click on your OS drive (C:), open Properties, go to the “Tools” tab, and run a check for drive errors.
If you’re using an Nvidia GPU, the issue might also be related to the graphics driver. Try uninstalling the driver using DDU and consider rolling back to a previous version. Nvidia drivers have had serious bugs in recent years.
