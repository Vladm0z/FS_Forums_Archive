FatsharkJuliaCommunity Support • 2026-06-25 10:22:54

Hi Clanking, I’d recommend removing your AppData entirely; please be aware will reset any custom options. Failing that, let me know, and I’ll pop it in to our database.

Step 1: Disable Steam Cloud Saving

If Steam Cloud saving is enabled for Darktide, this may automatically restore the AppData and consequently cause the issue to resurface.

  1. Navigate to your Steam library
  2. Right-click Darktide
  3. Select ‘Properties’
  4. On the ‘General’ tab, scroll down to ‘Steam Cloud’
  5. Disable ‘Keep game saves in the Steam Cloud for Warhammer 40,000: Darktide’

Step 2: Delete AppData

NOTE: By deleting your AppData, operative loadouts and custom keybindings will be reset. You may wish to make a back-up of the directory in the event deleting your AppData does not work to resolve the issue.

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to: AppData\Roaming\Fatshark
  4. Delete the entire ‘Darktide’ directory

Step 3: Verify Integrity of Game Files

You will then need to use the ‘Verify Integrity of Game Files’ option, which is accessible via the Steam client and will ensure the installation is complete.

  1. Right-click Darktide in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify Integrity of Game Files’ button
  5. When complete, close and reopen Steam

I have an update. After looking around online I found that I am not the only one experiencing issues with AMD cards in Darktide. I stumbled upon a list of ini-file configurations that many people claimed to have success with. I tried these out myself and found that practically all my issues were solved. There is still some delay on rendering textures from time to time, but nowhere near as bad as it used to be. On top of that, my game runs incredibly smooth at high fps now, that is with all graphics settings set to high. Please find the list of changes below.

In win32_settings.ini:

fullscreen = true

streaming_texture_pool_size = 1024

In settings_common.ini:

feedback_streamer_settings = {
  feedback_buffer_size = 4
  max_age_out_tiles_per_frame = 8 CHANGED
  max_streaming_tiles_per_frame = 8 CHANGED
  max_texture_pool_size = 1024
  max_write_feedback_threshold = 0.009
  min_write_feedback_threshold = 0.005
  staging_buffer_size = 4
  threaded_streamer = true
  tile_age_out_time_ms = 5000
  tile_staging_buffer_size = 96 CHANGED

mesh_streamer_settings = {
  disable = false
  eviction_timeout = 5
  frame_time_budget = 1
  io_buffer_budget = 10240
  limit = 2000 CHANGED

streaming_buffer_size = 32
streaming_max_open_streams = 32 CHANGED
streaming_texture_pool_size = 1536 CHANGED
surface_properties = "application_settings/global"
texture_streamer_settings = {
  streaming_buffer_size = 64
  streaming_texture_pool_size = 1536 CHANGED

EDIT: indeed the game runs much smoother now and texture pop-in/rendering issues are less. These issues do however still present themselves, especially the weapon LOD after swapping. It sometimes takes very long to render all the details and this happens pretty much all the time while playing. This also did not fix the the artifacts that replace textures sometimes as you can see in my pictures.
