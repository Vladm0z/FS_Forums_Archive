DashHandsome • 2025-11-09 06:48:51

Actually another thing I thought of:

Do you have virtualization based security on? A bit over a year ago I turned it on and it fixed a lot of my access violation crashes.

All you need is to turn virtualization on in your bios (labeled SVM for AMD CPUs) and it should be on by default. I’d tell you to check the CPU tab in your task manager to be sure but the latest version of windows will duplicate your task manager in the background if you click X to close it

You can check the device security tab of windows security and see if core isolation is enabled. Click core isolation details and make sure memory integrity is on too.

Although if you already have it on and you’re still crashing then this windows update is just that much more irritating
