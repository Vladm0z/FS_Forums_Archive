Sorry to hear this @Turra

We checked your log and can see a genuine GPU memory error, but the data shows neither the card nor system RAM were actually full. It could potentially be an allocation hiccup.

I recommend trying the following:

  • Ensure you have the latest AMD driver installed. If the issue persists, please try uninstalling your current GPU drivers using a dedicated driver removal tool e.g. DDU (Display Driver Uninstaller) and then installing clean latest drivers
  • It may help to try dialing back custom settings e.g. specifically turn off ray tracing, drop texture quality a notch etc. and see if the crash persists; as this combination at ultrawide resolution is the heaviest VRAM allocation profile you can run
  • Run Steam ‘Verify integrity of game files’ (you may have tried this already, but a second sanity check may be worthwhile)
  • Close any background overlay/capture apps (MSI Afterburner, Discord overlay, RTSS, etc.) before playing, as it’s a common contributor to allocation contention

Please let me know how things go.
