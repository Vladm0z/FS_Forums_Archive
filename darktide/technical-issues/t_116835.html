Whenever I try to play Warhammer 40,000: Darktide, it feels like a gamble whether the game will crash or take an extremely long time to load. I frequently encounter a Fatal Error popup stating that the game failed to read data, or an in-game message saying:

“Synchronization Error – unable to synchronize with other players (error code 1 / error code 2)”

Before the crash or synchronization failure, I can see in Task Manager that my disk usage spikes to 100%, with 90%+ coming from Darktide.

I do not experience this issue with any other games. I have followed all the troubleshooting steps provided by Fatshark (link below) with no success:
https://support.fatshark.se/hc/en-us/articles/7709661288733--PC-How-to-Resolve-Crashes-in-Darktide there was also another one I cant find right now but it said to change DNS or what not still no success

To rule out a broader system issue, I have launched Vermintide immediately after a Darktide crash while disk usage was still at 100%. Vermintide runs normally and the disk usage stabilizes, which suggests the issue is isolated to Darktide.

The only times Darktide has been playable are:

Immediately after verifying file integrity (works for 20–30 minutes)

Shortly after reinstalling the game (works for about an hour)

After that, the crashes and synchronization errors return.

I have noticed that when Darktide causes disk usage to spike to 100% in Task Manager, the average response time jumps to ~3000 ms. This behaviour does not occur in any other game.

Once disk usage reaches 100%, I can sometimes stabilize it by changing operatives. Doing this after each run prevents the disk usage from remaining maxed out. If I do not change operatives, disk usage tends to climb again toward the end of the next run, at which point audio starts cutting out and the game usually disconnects or kicks me back to the menu.

Since using the “change operative” workaround, crashes have been significantly reduced, although the underlying issue still persists.
