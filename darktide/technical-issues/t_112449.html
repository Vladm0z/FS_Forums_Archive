Issue Description (Required):

On CachyOS (Linux), if mesh_streamer_settings aren’t set to disable = true in the user_settings.conf file, then the game’s mesh streaming is broken during live game sessions where doors, weapons and other objects frequently display in a lower quality mesh model, which makes iron sights unusable on most weapons (and their skins).

There currently exists a fix by setting this as disable = true, but this is quite a brutal one way fix that can affect performance (by loading everything all at once).

I’ve seen this issue reported before for AMD graphics cards but I’m using an Nvidia graphics card, so I don’t know how this is happening. Please look into this as a whole.

[PC] Do You Use Mods? (Optional):

Yes, and I’ve tried disabling them

Reproduction Rate (Required):

Constant (100%)

Platform (Required):

Apologies for necro’ing this report, but I’ve been having this issue for a long while now as well, and I’d also like to provide some screenshots. This glitch makes it incredibly difficult to ADS with bolt weapons and revolvers as well. Some maps have extremely broken visuals in some sections, and the results are particularly egregious in gamemodes like Expeditions, or where enemy density is high.

This issue is persistent across multiple distros & versions of Proton, and is not exclusive to AMD cards, so it’s probably an issue with translating from DX12 to Vulkan in general.

Edit: It is important to note that while I can disable mesh streamer, it causes my game to either disconnect me from matches or crash entirely when trying to load in with about a rate of 80% due to my hardware specs, so I am ultimately forced to play with broken LoD’s & viewmodels.

Edit 2: I also understand that even if Fatshark does not support Linux officially, there is next to no solution for the player to resolve this issue on their own unless a Proton version comes out without this error (highly unlikely). In the meantime, the only likely solution can come from Fatshark directly, whether it be by releasing a patch, or by other means. While it may not seem worthwhile at the time being, with the imminent release of the Steam Machine from Valve, there will be a noticeable uptick in players running the game on Linux, and it might be in Fatshark’s best interest to at the very least fix minor graphical issues such as this, since the game seems to run fine performance-wise on a wide array of hardware & a good handful of Proton versions (I’ve personally had a good experience with Hotfix, Experimental, GE [10-32], and 10.04).
