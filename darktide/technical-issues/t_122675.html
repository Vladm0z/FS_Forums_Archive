iofsauron • 2026-07-06 10:03:09

I have solved my problem and am putting it here in case it helps anyone else.

I added “/home/user/.local/share/goverlay/fgmod/fgmod-uninstaller.sh” to my launch settings, then started the game. It fails, so then you remove this option and verify your files. It will find a number of files and download them. Then run the game again and it’s all good.
