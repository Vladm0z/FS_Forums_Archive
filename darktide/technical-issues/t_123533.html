FatsharkLevCommunity Support • 2026-07-03 11:06:09

@saintlevias sorry to hear this.

Firstly, please try verifying integrity of game files:

  1. Right-click Darktide in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify the Integrity of Game Files’ button
  5. When complete, close and reopen Steam

Failing this, next try a clean reinstallation of Darktide, which involves deleting your AppData (please note custom settings e.g. keybinds, graphics, loadouts etc. will be reset):

https://support.fatshark.se/hc/en-us/articles/360034118394--PC-How-to-Perform-a-Clean-Re-Installation-of-Vermintide-2-or-Darktide

Please let me know how this goes.
