We’ve noticed a small increase in reported Backend Errors after the No Man’s Land update.

We’re looking into it, and updates will be shared in the comments below and linked here as we learn more.

In the meantime, please help us investigate this issue by:

  1. Sharing your region and the name of your ISP with us
  2. Attaching your most recent console log. These can be located using the relevant instructions below:

Steam

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to AppData\Roaming\Fatshark\Darktide\console_logs
  4. Locate the console log that corresponds with the session in which the issue occurred, by looking at the timestamps in the log names

Microsoft Store

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
  3. Navigate to AppData\Roaming\Fatshark\MicrosoftStore\Darktide\console_logs
  4. Locate the console log that corresponds with the session in which the issue occurred, by looking at the timestamps in the log names

Thank you for your patience and cooperation!
