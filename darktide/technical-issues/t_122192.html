FatsharkLevCommunity Support • 2026-06-08 11:07:50

Sorry to hear this @T4alon

I suspect it’s a Steam permisions or settings mismatch that’s causing this.

Shot in the dark, but in case the GPU adapter is muddled, please try:

  1. Press the Windows key + R
  2. Enter %appdata% within the search input and select ‘OK’
    Navigate to AppData\Roaming\Fatshark\Darktide
  3. Open your user_settings.config file
  4. Find the setting named ‘adapter_index’
  5. Change this setting value to adapter_index = 0
    (If the adapter_index value is already set to 0, please try changing this to 1 instead)
  6. Save your user_settings.config file
  7. Launch Darktide as usual

Otherwise, solid shout from silentbob515 above, to try running Steam as Administrator.

Failing this, please can you also provide your most recent console log so we can take a look under the hood?
