FatsharkLevCommunity Support • 2026-09-22 16:46:05

Thanks @TurboVette

We’ve reviewed your logs, and the blank screen and Backend Error appear to be two separate issues.

  • The slow loading/blank screen will be your HDD drive. It appears boot was stalling on resource loading for 18+ seconds. Right after a reinstall, Darktide also has to rebuild the shader cache and unpack a lot of data, which hits a slow disk even harder. Moving the install to an SSD (or letting it fully settle for a session or two) should noticeably help here.

  • For the Backend Error, we can see your client tried to reach our login service, but the request never left your PC and failed at DNS lookup, timing out after 5 seconds, twice in a row, before the game was closed. This could indicate a network path issue.

We had no outage at this time, so we suspect this to be a local network hiccup (router, ISP DNS, VPN, or security software interfering).

I recommend to try the following:

  • Flush your DNS:
  1. Run the Command Prompt as an administrator
  2. Enter the command:
    ipconfig /flushdns
  3. Restart your PC

  • Change your DNS to 1.1.1.1. There are different providers, but as an example, please see: Set up 1.1.1.1 on Windows · Cloudflare 1.1.1.1 docs

  • Disable VPN if you are using one, and check Anti-Virus, Firewall, or any other internet security software; and ensure nothing is blocking Darktide. It may be helpful to add appropriate Anti-Virus/Firewall exceptions for Darktide.

Please let me know how things go!
