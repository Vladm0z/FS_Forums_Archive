specty • 2025-06-26 08:36:51

Probably the final update I’ll be providing on this issue, but it turns out DLSSFG is having issues specifically with Gsync and it’s possible to rollback to an older driver version to resolve it.

I’ve currently rolled back to Nvidia driver version 566.36 and DLSSFG seems to work properly with Gsync, the only noteworthy thing about every driver version afterwards is that they’re when Nvidia started rolling out the DLSS4 changes for games that support it.

I hope this can give a definitive cause as to why I’m having this issue with DLSSFG as this issue has been persisting for a very long time.
