FatsharkLevCommunity Support • 2026-04-29 09:24:54

Sorry to hear this @Mersi

They appear to be very niche Deadlock crashes, one with only a single occurrence unique to your system.

‘AMD FSR 3.1 Frame Generation’ in launcher ‘Settings’ menu has been unstable lately. Just in case this is related, please check that this is disabled.

Otherwise, can you try rolling back to an older driver version e.g. Adrenalin 25.9.1 and check if the crashes persist?

If you encounter crashing still, it may then be worth trying a clean reinstallation of Darktide which involves deleting your AppData. (please note custom settings e.g. graphics, keybinds, loadouts etc. will be reset):
https://support.fatshark.se/hc/en-us/articles/360034118394--PC-How-to-Perform-a-Clean-Re-Installation-of-Vermintide-2-or-Darktide

Please let me know how this goes.
