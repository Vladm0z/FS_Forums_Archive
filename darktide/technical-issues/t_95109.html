For example 13 and 14 K intel CPU’s has a known HW issue. Which seems to be triggered alot for oodle decompression.

radgametools.com

Intel Processor Instability Causing Oodle Decompression Failures

RAD Game Tools' web page. RAD makes Bink Video, the Telemetry Performance Visualization System, and Oodle Data Compression - all popular video game middleware.

This is the only known cause for causing this 100% otherwise it’s something else that is broken on the system that is causing this. Unless this specific file would be broken, but then we would see it more often.

The current solution for this is stated in a earlier link

Fatshark

Intel i9 13900k/14900k and Intel i7 13700k/14700k: Underclock ‘Performance Core’ Speed

It has been noted that players with the Intel i9 13900k/14900k and Intel i7 13700k/14700k CPUs are prone to these crashes. Players have been able to work around this by underclocking the ‘Performance Core’ speed using Intel XTU, from x55 to x53.

Also Intel has commented on this issue in the passed year and stated that the issue originates from the motherboards that they don’t follow the Intel guidelines and allows the CPU to use more power than recommended. If I recall.
