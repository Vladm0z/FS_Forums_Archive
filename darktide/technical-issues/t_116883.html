Jumping off Julia’s suggestion cause Windows experience with bluetooth is weird:

That setting may end up turning itself back on.

You can also try changing the in game mic settings to push to talk or off and/or setting a different mic to be the default device in Windows audio settings Before starting the game.

Darktide and any other game with voice chat based on detecting your voice requires the mic to be always “on” and listening for input above a certain noise level which has a side effect of automatically cutting sound output.

This is one of those weird bluetooth bandwidth issues that Windows tries to handle for you but it kinda falls apart with games. You can’t really have both incoming audio and outgoing mic input without demolishing the quality.
