blood_2899 • 2026-03-29 16:51:17

I’m pretty sure we failed to communicate here

There are two different frame generation technologies you can use in darktide when on AMD RX 9070XT.

  1. Frame generation by AMD FSR 3.1 Frame Generation. You turn it on via in-game or launcher options:

image783×565 98 KB

Turning AMD FSR 3.1 Frame Generation on will cause the game to crash on RX9070XT. Turning it off will make the game playable but with lower framerate. Extra frames with FSR Frame Gen are generated by the game engine, not at driver level. Driver can only override algorithms at game engine to use FSR 4 or FSR Redstone if available for the game (which are available for Darktide).

  1. Frame generation by AMD Fluid Motion Frames 2.1. You turn it on via AMD Adrenaline Software options:

image945×244 27 KB

Turning AMD FMF 2.1 doesn’t cause the game to crash on RX9070XT. Turning it on improves framerate, but there are visual artifacts. Extra frames are generated by the AMD driver, and algorithms to generate picture don’t have access to game engine/game files. The frame pacing is uneven, UI has ghosting effects during transitions, motion vectors are handled poorly, shadows are inaccurate.

The temporary solution to the issue is to turn off FSR 3.1 Frame generation via in-game/launcher options. To have acceptable framerate you can turn on AMD FMF 2.1, but be prepared to visual artifacts and lower picture quality.
