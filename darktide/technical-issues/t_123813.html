This doesn’t appear to be a GPU hang, but driver version 26.6.4 is unstable presently. Also to note, the error references a module relating to AMD FSR.

Firstly, could you try rolling back to driver version 26.6.1?

KNOWN ISSUE: "DXGI_ERROR_DRIVER_INTERNAL_ERROR" on AMD Driver Version 26.6.2 & 26.6.4Technical Support
It has been observed that the AMD driver versions 26.6.2 and 26.6.4 are resulting in players experiencing a DXGI_ERROR_DRIVER_INTERNAL_ERROR error on launch. In the meantime, we recommend rolling back to the last known stable version 26.6.1. This should immediately resolve the issue. Thank you for your patience as we look in to this.

Otherwise, some folk have had success in resolving crashes with the latest driver version 26.6.4 after capping mhz clock speeed
