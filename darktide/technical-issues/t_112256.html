@nickdelcat2424 sorry to hear this. Usually a GPU hang/crash and black screen as a result of tabbing out can be caused by GPU driver issues, or perhaps different display refresh rates between the game and your desktop.

https://support.fatshark.se/hc/en-us/articles/360021233554--PC-How-to-Perform-a-Clean-Re-Installation-of-Your-NVIDIA-GPU-Drivers

It’s also worth checking your display refresh rates are synchronized:

  1. In Windows, go to ‘Display Settings’
  2. Go to ‘Advanced Display’
  3. Ensure your desktop refresh rate matches Darktide

You can set a specific framerate cap for Darktide in your user_settings.config file:

  1. Press Windows + R
  2. Enter ‘%appdata%’
  3. Navigate to Fatshark > Darktide
  4. Edit your ‘user_settings.config’ file
  5. Press CTRL + F and search in the config file for ‘nv_framerate_cap’
  6. Set this to your desired value and save changes
  7. Launch Darktide as normal
