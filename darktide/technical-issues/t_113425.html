FatsharkJuliaCommunity Support • 2025-10-09 08:23:32

Hi, I notice you have an i7-13700K. The 13th and 14th Gen Intel CPUs have a manufacturing error, which usually presents in the shape of data corruption errors in Darktide but sometimes with other crashes like this.

You should be able to work around this by underclocking the ‘Performance Core’ speed using Intel XTU, from x55 to x53.

For more information on the underlying issue, please refer to: Intel Core 13th and 14th Gen Desktop Instability Root Cause Update - Intel Community

Hi, thanks for the reply!

I found the root cause actually. Turns out it wasn’t the game, drivers, or even Windows — it was my M2 drive installed in the wrong slot on my motherboard. Moved it from GPU to socket near CPU and it worked like a charm.

However, I’d try your suggestion with Intel underclocking as well. Thanks again!
