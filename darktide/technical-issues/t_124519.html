When running Darktide the Service Host process often starts hogging memory, >10 gigabytes, until Darktide crashes due to running out of memory. This can happen over like 10 minutes of gameplay, and I need not be in a mission. The only workaround at the moment is keeping task manager open and killing the process (repeatedly) every time it starts hogging memory. This happens often enough that I have to kill the process multiple times in a mission, but has never happened when not running Darktide. The process can also stick around hogging the memory after Darktide is closed.

The specific service as it’s listed in Task Manager was service host windows push notifications user service_<number here>.

I’ve managed to ‘fix’ the problem by disabling the user service responsible for the notifications in the windows registry. I never cared for notifications much anyway (they were already disabled in the windows settings). I used the following command:

reg add "HKLM\System\CurrentControlSet\Services\WpnUserService" /v "Start" /t REG_DWORD /d "4" /f
