In windows settings. System → Display → Graphics

image988×679 25.2 KB

If Darktide.exe profile not there you can add using “Add Desktop app” to point to darktide.exe

But there is dropdown option to “Let windows decide” or you can manually select GPU

image930×170 6.59 KB

To also confirm once game loaded.

Task manager will show GPU 0 or 1, so probably GPU 1 is your discrete GPU if laptop.

image196×128 2.12 KB

Task manager → Details tab, right click columns headers to add GPU information. Then you’ll see if Darktide is using correct one.
