How To Fix AMD's Driver Crashing With DDUPerformance Feedback
Issue Description (Required): Edit: If you are coming here with a 9070 series card, Windows has been forcefully changing your drivers to an older version regardless of what settings you change or homegroup policies you have in place to stop that. I’m putting this here to hopefully help others avoid the same problems. I previously helped a friend through …

keep in mind Windows broke mouse and keyboard inputs in the recovery screen so you can’t get to safe mode that way I recommend just using the AMD driver cleanup utility which kicks windows into safe mode for you and back out when it’s done. You can ignore everything about clearing your steam cloud save I think. Also the driver link I used is old so you’ll have to search the most recent one. Yes, going offline is needed so downloading the full driver instead of the auto detect is necessary.

give my post a read through for more details but your order of things should be:

-download your full driver and the AMD cleanup utility
-turn off wifi/pull your ethernet
-clear the darktide appdata folder
-use the cleanup utility to go into safe mode and wipe your drivers and it should restart to bring you back out of safe mode
-install the newest driver
-restart again
-go back online and try the game again

Also some general AMD advice for Darktide:

The game hates extra overlays. Turn the AMD one off. There’s a separate popup to confirm that FSR4 is working now so you don’t have to worry about that

image757×156 9.69 KB

Most games are fine with this stuff but Darktide in particular is annoyingly fragile when it comes to being messed with. Set darktide to use your global profile and don’t enable any of that HYPR-RX stuff when asked. FSR4 is fine but turn off surface format optimization and set tessellation to application controlled. Yes that means no anti-lag but that’s fine because it makes the psyker shields all psychedelic. Can’t get bugs like this in any other game
