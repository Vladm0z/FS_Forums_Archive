FatsharkJuliaCommunity Support • 2025-11-17 10:38:15

Hi Petrowi, I can see the Intel(R) UHD Graphics is currently set as your primary GPU instead of the NVIDIA GeForce RTX 4050.

This can cause stability issues, as your primary GPU doesn’t meet Darktide’s requirements. Please see the steps listed below to resolve this issue:

Step 1: Check Monitor Connections

Ensure your monitors are connected to the dedicated GPU ports on the back of your PC, rather than the integrated GPU ports.

Step 2: Perform a Clean Driver Re-Installation

  • [PC] How to Perform a Clean Re-Installation of Your NVIDIA GPU Drivers
  • [PC] How to Perform a Clean Re-Installation of Your AMD GPU Drivers

Step 3: Set Your Dedicated GPU as Default

For NVIDIA GPUs

  1. Right-click the desktop and select the ‘NVIDIA Control Panel’
  2. Navigate to ‘Manage 3D Settings’ > ‘Program Settings’
  3. Locate Steam within the list of programs
  4. Within the ‘Select the preferred graphics processor for this program:’ dropdown, choose the NVIDIA GPU
  5. Then locate Darktide within the list of programs, and repeat the above step

For AMD GPUs

  1. Right-click the desktop and select ‘Radeon Settings’
  2. Navigate to ‘Preferences’ > ‘Additional Settings’ > ‘Power’ > ‘Switchable Graphics’ > ‘Application Settings’
  3. Locate Steam within the list of programs
  4. In the ‘Graphics Settings’ column, assign the ‘High Performance’ profile
  5. Then locate Darktide within the list of programs, and repeat the above step

Step 4: For Windows 10 Users

  1. Navigate to ‘Settings’ > ‘System’ > ‘Display’
  2. Select ‘Graphics Settings’
  3. Select the ‘Browse’ button and locate the Darktide executable (Program Files (x86)\Steam\steamapps\common\Warhammer 40,000 Darktide\binaries)
  4. Select the ‘Options’ button
  5. Choose ‘High performance’ and save your changes

Step 5: For ASUS Notebook Users

  1. Configure NVIDIA Optimus/AMD Switchable Graphics using the instructions here: ASUS FAQ: GPU Switching Settings
