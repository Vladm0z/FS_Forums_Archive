FatsharkLevCommunity Support • 2026-06-23 12:00:15

We are aware of an issue for the Skitarii Deluxe Bundle DLC which requires entering the hub with a Skitarii operative, before the deluxe customizations and content is accessible.

To resolve the issue after purchasing the Skitarii Deluxe Bundle:

  1. Launch Darktide
  2. Proceed to the Mourningstar Hub with any existing operative
  3. Deluxe items and customizations should be granted
  4. Back out to character select and then create a Skitarii operative with deluxe customizations available

If the above does not work, please try:

  1. Launch Darktide
  2. Create a Skitarii operative (deluxe customizations may not be available)
  3. Proceed to the Mourningstar Hub
  4. Deluxe items and customizations should then be granted
  5. Go back to operative selection to create a new Skitarii with deluxe customization options, or visit the Barber Chirurgeon to modify appearance for deluxe customization options
