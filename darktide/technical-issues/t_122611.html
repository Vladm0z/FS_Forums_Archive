FatsharkLevCommunity Support • 2026-06-23 13:32:19

@Havelock we’ve seen another report of this. It’s related to the ‘lua_cjson_pluginw64_release.dll’ not being loaded correctly.

First thing to try is verifying integrity of game files:

  1. Right-click Darktide in your Steam library sidebar
  2. Select ‘Properties’
  3. Select the ‘Local Files’ tab
  4. Select the ‘Verify the Integrity of Game Files’ button
  5. When complete, close and reopen Steam

If that doesn’t work, please check Anti-Virus software and ensure that it isn’t quarantining any Darktide files - or this dll specifically. Restore any quarantined files, and adding Anti-Virus and Firewall exceptions for Darktide should hopefully help!
