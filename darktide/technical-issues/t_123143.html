FatsharkLevCommunity Support • 2026-06-30 07:46:13

Thanks for the update @drathjennifer

Next, please can you try the following:

  1. Right-click 'Warhammer 40,000: Darktide in Steam Library
  2. Select ‘Manage’ > ‘Browse local files’
  3. Navigate to the 'bundle’folder - file path should be similar to \Steam\steamapps\common\Warhammer 40,000 DARKTIDE\bundle
  4. Search this folder for ‘metadata_database’
  5. Delete the ‘metadata_database.db’ file
  6. Then, verify integrity of game files via Steam once again to generate a new ‘metadata_database.db’ file
  7. Launch Darktide as usual

This specific file is needed to be able to load into Expeditions missions - so if it has become corrupted in some way, hopefully doing so will straighten things out
