Something to do with steam or the game being run as administrator:

The “Unexpected App ID” error on Steam usually means a steam_appid.txt file exists in the game folder incorrectly, or the game is launching in Administrator mode when it shouldn’t be. Delete the steam_appid.txt file in the game’s directory and disable “Run as Administrator” on the executable to fix it
