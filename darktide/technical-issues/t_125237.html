I would bet on driver…
So many problem when I was using Fedora, and problems that I have seen also with my son’s computer under bazzite.

From Claude, that checked the log (I love AI - yes not good for environment )

  1. Disable DLSS Frame Generation temporarily to check whether the freeze/crash still occurs.
  2. Enable Hardware-Accelerated GPU Scheduling in the system settings, if the environment allows it (this was disabled in the log).
  3. Check and update the NVIDIA driver version, as well as the version of Proton/Wine being used — this looks like a Wine 11.0 compatibility layer running on Linux, and GPU fence synchronization stalls (RI::wait_for_fence, present_windows/present) between the main and renderer threads are a known pattern with this engine (Stingray/Fatshark) under Proton, especially combined with DirectX 12 to Vulkan translation and a proprietary NVIDIA driver.
