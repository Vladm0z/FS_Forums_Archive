Duplicate post from Performance subforum. But just to raise awareness as it annoyed me.

Just FYI about new nvidia app and legacy control panel going forward.

Below from reddit and happened to me - Seems Nvidia app on new install used to give option to disable optimisations during process. Now you have to install, then go one by one per game to hit revert:

“Warning when using DDU to install, the ‘Automatically optimise newly added games and apps’ setting in the app seems to default to ON with no option to turn it off during the onboarding dialog any more. This meant I needed to go through and revert the “optimisations” in each game, bit of a pain.”

Remember to also turn off “automatic optimised newly added games” in Nvidia app.

Also about legacy control panel. New drivers going forward won’t include but:

“Existing installs of the NVIDIA Control Panel will remain on users’ systems, unless they perform a clean installation, and users who still need the NVIDIA Control Panel can continue to download it from the Microsoft Store, but we won’t be adding features, fixes, or other changes.”

and…

As the nvidia app optimises game automatically, even after reverting before game launch it messed with user_settings.config file already and reset my mod options settings somehow. So recommend backup of user_settings.config to copy back in afterwards.

You can install driver only

Latest version won’t include legacy control panel - But you can still get that separately from MS store. But they won’t add new features to it anymore.

When doing DDU and staying off the internet to prevent windows pulling down drivers. You must be connected to internet before installing Nvidia app to allow pop up on boarding process to choose not to auto optimise games. Otherwise it will do it automatically and you have to revert each one by one.

In my case, revert worked but it messed with mod settings because graphical options are stored in same file user_settings.config, so I used backup of my user config to copy back in. So “revert” did not put in original mod options settings.

As above post could skip legacy control panel, skip nvidia app and use Nvidia Profile Inspector or Revamp version. Then if a driver comes along of major DLSS revision you have to wait day or two for Nvidia Profile Inspector new version to use it for override i.e. When we went DLSS 4. to 4.5. Or indeed any new features for it to play catch up.

Of couse there may be things might still need Nvidia app or third party app as Nvidia Profile Inspector can’t do. i.e. Digital Vibrance and Automatic Shader Compilation.

If you install driver only. DLSS preset is K for all DLSS SR modes Ultra Performance all the way to DLAA. So you’re going to need Nvidia app/Nvidia Profile inspector to use M or L models.

Overriding DLSS preset with “Recommended” means the preset will be automatically set dependent on DLSS SR mode. UItra Performance sets to L, Performance to M and K for the rest. Resolution is not part of factor in automatic preset it chooses.

Or Override with one preset regardless of DLSS SR mode i.e. Preset M across Ultra Performance all the way to DLAA.

Sometimes you do want to say F it - Driver only and nothing else.
