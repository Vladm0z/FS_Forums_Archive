I would like to inquire about the mod rules. I’ve noticed that some mods have a significant impact on balance. Will this be considered cheating and result in a ban?

Regarding the Dog Whistle mod, there are concerns about it being exploited in a way that undermines balance. For the Arbitrator class, this mod allows players to command their Cyber-Mastiff to attack specific, filtered targets . This effectively replicates a core function that normally requires investing a talent point in the skill tree. For the Skitarii class (likely referring to the Veteran class modded to resemble one), the mod can similarly direct servo-skulls to prioritize high-value targets like snipers and gunners .

This creates a significant imbalance, as players using this mod can, for example, send a servo-skull to engage a sniper dozens of meters away without any player input or talent investment. This gives them a considerable advantage in effectively neutralizing threats, which is unfair to players who are not using the mod.
