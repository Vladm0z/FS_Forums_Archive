I have over 600 Hours in the Game so far and i am going to buy the DLC since i think it is good value but that said prior to that i haven’t spend a single Cent on the Game so far since i got it on a Discount.

Why?

  1. A rotating FOMO Shop prevents me from buying the Cosmetic i want and i don’t want to support that practice.
  2. Ten Bucks for a single Cosmetic Set for one Class is simply not worth it.
  3. 500-1000 Aquillas for a single Cosmetic for one single Weapon isn’t worth it.

Think about it : How many, with me its at least one and everyone i talked to and read about it is of the same Opinion, isn’t buying any Cosmetic at all due to their Price / not good value instead of many if they were lower priced?

For example :

I would have bought multiple Cosmetics by now already if they were cheaper and or not rotated in a FOMO Shop…instead of none.

I would have bought multiple Weapon Cosmetics if they came in a bundle / had the Skin for multiple Weapons…instead of none.

Or if at least the Game would get more frequent and larger Updates it would encourage me, and probably many more, to buy Cosmetic even with the current pricetag / FOMO because the Game as a whole would be more fun and feeling good with no buyers-regret or some ‘sunk-cost fallacy’ to buy Stuff to support it because one knows the Game is getting frequent and great Updates…instead of what are simply drip-fed Updates once in a blue Moon.

The Game has such massive potential. People want to play it.

This isn’t meant as Hate or something. The Game is absolutely great but it has so much insane untouched potential. Please Developers make more of it even if just for Business / Money-sake because people want to play the Game, continue the Game and cash in if Stuff is fairly price, has good value and the Game is good.
