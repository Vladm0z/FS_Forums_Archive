BizarreSalp • 2026-07-25 22:43:37

With three debuffs, it would work out perfectly to break the ability into four tiers. For simplicity’s sake I’m going to put these into ten-second tiers. IE, you can run the ability a max of 40 seconds (I know this is far too long, but a nice round number is easy to visualize, so please bear with me).

If you start Rampaging and go from 1-10 seconds and then end it, you get no downsides.

If you go from 11-20 seconds, you get 1 debuff.

If you run it for 21-30 seconds, you get 2 debuffs.

And then if you run it to the max you get all 3 debuffs. The value of the debuffs could be adjusted to be more appropriate.

It would make the ability a lot more interesting, I think, since you would have to weigh the pros/cons in each situation. At least better than currently.

You could even have the bonuses scale with time spent in the mode, so that it’s a light buff at the start, but gets stronger.
