Peril Equilibrium should pull peril toward 75%, not just generate it.

grok_image_17909500861112096×944 222 KB

The new Peril Equilibrium node only generates 2% peril per non-warp hit while below 75%. The old Tranquility Through Slaughter quelled 4% on non-warp ranged crits, so gunpsyker builds that leaned on Scrier’s Gaze to keep peril low are effectively dead now. You’re forced to either run a staff or manually quell between every burst, which kills the whole playstyle.

My suggestion: make it a true equilibrium node. If peril is above 75%, non-warp hits quell peril. If it’s below 75%, they generate it. That way the node still ties non-warp weapons into the peril system, which I think is the actual design goal while restoring the gun builds that made Scrier’s Gaze viable.

It would also fix the pathing issue: Peril Equilibrium currently gates access to Puppet Master, which is a broadly useful talent that shouldn’t be locked behind a niche node.

Boohoo note: lost a whole character built around guns, that relied heavily on that node.

Just an idea. Have a great day!
