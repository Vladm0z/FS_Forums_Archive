Note that I have been using mods forever, if any of these mods already a part of the base game please tell me.

  1. Solo Play: There are many people who would like to play solo, the mod exists, but it should be a part of the base game.
  2. Full Auto and Keep Swinging: Both of these mods improve the game greatly for people with carpal tunnel or other issues (or simply people who hate spamming clicks) to play the game.
  3. Chat Block: This mod forces you to block if you have a melee weapon out and open the chat, it was added to Vermintide years ago, should’ve been part of base Darktide.
  4. Ammo and Medical Markers: This mod improves the markers of health packs and ammo packs, additionally, it gives the big ammo pickups a distinct icon, which is nice.
  5. Alternate Grenade Icons: This mod allows you to tell the grenade type of teammates, and if they can actually use grenade pick ups or not.
  6. Stimms Pickup Icon: Colors the stimms icons, a white stimm on the UI tells you nothing other than the fact that your ally has a stimm.
  7. Crosshair Remap (Continued): This one would be nice to have, you can never know how much a simple change of crosshair could improve a weapon’s feel.
  8. Weapon FOV: Allows to change the FOV of the first person view model for each weapon, can drastically improve game feel.
  9. Creature Spawner: A must have if you want to test anything on hordes of enemies, or a group of tough enemies.
  10. Talent Tree UX Improvements: Improves the talent tree interactions, becomes useless when there is only one viable build and there is no need to change things around, but still a good mod.
