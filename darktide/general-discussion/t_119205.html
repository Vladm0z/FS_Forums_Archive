anon73549677 • 2026-03-11 12:49:10
Padds:

The framework the modders are working is different to the devs.

Actually, this doesn’t appear to be the case! The mod author has included some pretty thorough documentation, including implementation notes:

Darktide has a complete bot ability system built into the behavior tree, but Fatshark hardcoded a whitelist that only allows two abilities. This mod removes that gate and injects the missing metadata so the existing infrastructure handles the rest.

Why does this infrastructure exist?

The bot ability system — behavior tree nodes, action queuing, ability extension — all work end-to-end in vanilla Darktide. So why did Fatshark build it and never turn it on?

  • Vermintide 2 inheritance: Both games share the same engine. VT2 bots use career abilities (dev blog) — the architecture carried over, but the ability-specific logic was never rewritten for Darktide’s templates.
  • Launch triage: Darktide launched in Nov 2022 in an unfinished state. In Jan 2023, Fatshark paused all new content to fix crafting, progression, and stability. Solo mode — and bot abilities with it — was shelved from “final stages of testing” to “not a priority.”
  • Ability system redesign: The Class Overhaul (Oct 2023) completely reworked abilities, adding talent trees with 3 combat abilities per class. Writing bot heuristics for a system in flux would have been thrown away.
  • Design philosophy: Fatshark wants bots as matchmaking placeholders, not capable teammates. A developer stated: “It’s easy to make great bots that can carry. It’s hard to make average ones. But average is the goal.”
  • Server architecture: VT2 was peer-to-peer (host runs bots locally). Darktide uses dedicated servers — solo play requires local hosting with added performance cost, which was never implemented officially.

BetterBots picks up where Fatshark left off: we populate the condition tables, inject the missing metadata, and add per-ability decision logic so the existing engine infrastructure can do what it was designed to do.
