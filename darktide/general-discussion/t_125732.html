Haven’t been here over a year but feel like I have to say something for the upcoming update.

I want to talk about stam regen delay reduction (SRDR) node that will get removed soon. Most players prob don’t realize how bad this is for the class because they don’t spec into it anyways but I just want to put it out there for the record.

The devs want vet to be almost like a range only class is absurd. Both melee and range combat are equally important to your survivability. Losing SRDR will hurt the class a lot. Why is it important? It defines how efficient the class is at kiting, moving, positioning in tough situations. Removing this node is so innocent. This is not gonna affect auric or below havoc 35 cause those are pretty much free win if you are skilled. But this is gonna hurt real bad in h40.

It’s super innocent (for lack of a better word) when devs update a class based on the idea that 4 players will always work together to their best abilities, or other players will always care for you.

I rather you don’t update vet tree. There is no point to have more skills/talents if you will be way weaker in close combat and kiting ability. This is absurd.

If you don’t know what I’m talking about try spec into this node now, get in a match, then run + slide while looking at your stamina. You will see that when you get back from sliding to running again the stamina is back up almost at same level. Basically it improves your survivability a lot if you have the mec. Pskyer can do it, Zealot can do it without the need of extra node. I’m willing to lose one skill point to get this ability because how critical it is. Now FS just gonna remove it and make the class do phew phew only. How innocent…
