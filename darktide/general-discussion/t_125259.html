Nexus Mods :: Warhammer 40,000: Darktide

Realms Server (Beta)

Adds LAN multiplayer support to Darktide. Every local single-player game also starts a LAN listen server.

With this mod, you can connect to games launched via Solo Play mod. This is very cool as it allows the player hosting the game to install mods that normally only affect Solo Play/Psykhanium and have them work for anyone who joins, even if they don’t have the mod installed themselves*. In other words, modders can cook up their own balance changes/modifiers/anything really and play those things with friends, just like in VT.

It’s time for a Tourney Balance Patch for DT
