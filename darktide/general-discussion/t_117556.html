Anyone give it a go yet?

In terms of it’s motion clarity during rapid movement. As static isn’t good comparison than going full motion.

How to enable

Official date is 13th Jan but people are opting into Nvidia app beta, close app. Open task scheduler, in there run the Nvidia app update manually. Then if you want you can opt out after and keep that beta version. Other methods DLSSTweaks (which could trigger anticheat games) or Nvidia profile inspector.

Preset K is DLSS 4.0

Preset M is DLSS 4.5 recommended for Performance DLSS. So I guess that means more catered for 4K users.

Of course can still set performance, balance, quality on top whatever preset on nvidia app/in game.

Over sharpening

Maybe it’s way of trying to hide some blur/ghosting on edges?

There is a bit of shimmering/over sharpening as if you cranked up sharpness on your monitor OSD control.

Expectations

Thing is most people would just choose “Latest” in global DLSS Override, call it a day but it will preset M DLSS 4.5 and people keep same DLSS balance, performance, quality setting in game. But it hits 20/30 GPUs more.

NVIDIA DLSS 4.5 costs 2–3% performance on RTX 50, RTX 20/30 may be hit with 20%+ drops - VideoCardz.com

It can catch a lot of people off guard. People would just go for latest DLSS override whatever GPU then realise it tanks performance more on older ones. No indication in Nvidia app of this.

To show DLSS indicator

Computer\HKEY_LOCAL_MACHINE\SOFTWARE\NVIDIA Corporation\Global\NGXCore

Create DWORD of ShowDLSSIndicator and decimal value 1024 (No reboot required after)

Testing

Since Darktide is very CPU bound. I used free Black Myth Wukong benchmark tool to go more GPU bound and it has fixed scenario runs. DLSS Quality 67% upscale, no RT, no FG, max graphics settings. Going from K to M preset is 4% hit on 5080.

VRAM

My VRAM usage went up around 30% in Darktide. But Darktide doesn’t use much VRAM anyway I guess.

Nvidia app release official updated with DLSS 4.5. Just to make things more complicated.

I want to show you this. FYI

“Recommended” now replaces “Latest”

So I set Global override as below, all “Recommended”:

Then say I set Darktide to use global override, which also applies “Recommended”

image450×245 5.45 KB

Now in game I set DLSS Performance it switches to Preset M

Whilst still in game and not restarted I switch to DLSS Quality it switches to Preset K

So Presets actually change in game with DLSS setting.

So for example if you wanted to and preferred Preset K and DLSS Performance specifically you will now have override as global or game specific Preset K to allow using DLSS Performance without it auto switching to Preset M but use K instead.

So if left as “Recommended”

DLSS Performance - It switches to Preset M.
DLSS Ultra Performance - It switches to Preset L
DLSS Balanced, Quality or DLAA - It switches to Preset K

I’ve been testing both presets L and M in Havocs at 4K

The biggest obvious difference is that new 4.5 model preserves lights/color better.
Meaning any effects like flames, flashes, projectors, captains refractor shields, particle effects simply looks far better than DLSS 4

Overall lighting looks better with the new DLSS 4.5, specially in Darktide where there is so many effects.

  • Preset L is more stable, meaning is “shimmers” slightly less, but cost more that M by around 10%.

WHICH IS VERY NOTICEABLE WHEN YOU HAVE RAMPAGING MODIFIER THAT KILLS PERFORMANCE FATSHARK BTW

  • Preset M runs better than L but makes distance objects look bit funky because of more aggressive over-sharpening.

If you run lower resolutions than 4K, you’ll have to decide if the better effects/lights are worth the performance + extra oversharpening.

TLDR:M or L look great in Darktide.
