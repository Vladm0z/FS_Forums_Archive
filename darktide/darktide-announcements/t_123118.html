Warband!

Hotfix 1.12.2 is now being rolled out on all platforms. This hotfix is focused on fixes for the Skitarii class, and also has some features and tweaks to improve the general Darktide experience.

Hotfix 1.12.2 patch notes

Features & Tweaks

  • Reduced the unlock requirement for the Pro-Trader (5) Penance from 100,000 salvage to 20,000 salvage.

  • Vanguard Enemies:

    • Sweep priority between head and shield hitzones have been equalized; this change will make it so less of the hits that visually should have hit the head will be consumed by the shield instead.

    • Tweaked the Weakspot damage multipliers as follows:

      • Dreg Vanguard 0.5 → 0.75

      • Scab Vanguard 0.5 → 0.65

    • Change to Damage over Time type damage behaviour. The initial hit will inflict stagger as expected, but the DoT damage itself will not contribute to the impact required to ”open” the shield.

  • Reduced the unlock requirements of the following Skitarii Penances:

    • Curse of Malfunction: 500 → 75

    • Corpuscarian Disciple: 5000 → 1500

    • Voltaic Warrior: 5000 → 2500

Fixes

General Fixes

  • Fixed an issue where the ‘Voltaic Emitter’ Ability could be obstructed by terrain, and improved the consistency of the Weapon Malfunction of Voltaic Emitter.

  • Fixed the ‘Heretical Artefacts’ coherency buff reducing rather than increasing the coherency radius.

  • Fixed an issue where Skitarius-specific height scaling where not applied in Mission Lobby and End of Round menus.

  • Fixed an issue where hogtied players could be moved to another respawn location when an alive player was right next to them.

  • Fixed an issue where the game would crash when trying to set keybindings in the options.

  • Fixed an issue where using the Skitarii ‘Chordclaw Strike’ Ability would not consume a Capacitance Charge after starting to sprint while aiming the ability.

  • Vanguard Enemies:

    • Fixed unaligned Stagger settings for post-broken shield state; all stagger animations should now play correctly.

      • This issue did not affect the enemy while the shield was active.

    • Fixed an issue that made it very hard to make a Vanguard enter its heavy Stagger state.

  • Fixed an issue where the Skitarii ‘Veteran Skitarius” Penance could fail to track progress if the player joined an already ongoing mission.

  • Fixed an issue where the Skitarii ‘Voltaic Resistance’ upgrade Talent for the ‘Integrated Refraction Emitter’ Blitz could fail to generate any Arc lightning when expiring.

  • Fixed an issue where Ability cooldown could not be decreased when the cooldown was paused while an Ability was active. E.g. Psyker Psykinetic’s Aura with Scriers Gaze.

  • Fixed an issue where the Phosphor Blast Pistol could display an incorrect animation status if a reload was interrupted at a very specific timing.

  • Fixed an issue where the 1st person camera position for Ogryn operatives would scale incorrectly depending on the Height value of the character.

  • Fixed an issue where Poxbusters could fail to be staggered by melee Pushes in some situations.

  • Fixed a missing variable in the description for the Skitarii ‘Advanced Combat Doctrines’ Ability Mortis Trials legendary buff.

  • Fixed Skitarii ‘Progressive Plating Matrix’ Talent buff icon using the wrong image.

  • Fixed Hive Scum ‘Speedloader’ Talent showing in the Tactical Overlay without description while active.

  • Fixed an issue where smoke from Veteran ‘Smoke Grenades’ was difficult to see under certain lighting conditions and video settings.

  • Added missing Vanguard localisation text.

  • Fixed a crash that could occur when calling in a Valkyrie Airstrike on Expeditions missions.

  • Fixed an issue where chat bubbles would appear below Skitarius characters instead of above them in the Mourningstar hub.

  • [PS5] Fixed a rare issue where disconnecting the controller could occasionally cause a crash.

Cosmetic Fixes

  • Fixed an issue where the Lens Colours could incorrectly blend between eyes on Skitarius Body 1.

  • Fixed visual issues with Thrice Blessed Eye of Admonition (Scorched Ironmantle/Mordian Pride/Darkweald Battleshade).

  • Fixed a visual issue with Mordian Cap with Psykana Collar.

Known Issues

  • Sometimes hogtied (respawned) players will be moved to a later respawn point despite the Strike Team not having moved past their area.

    • Fixed!

  • No loadout is equipped after Personality Scourging as DLC classes

    • Happens on Hive Scum, Arbites, and Skitarii.

      • Hive Scum specific issue:

        • When personality scourging as Hive Scum, the headgear is changed to the chosen gang’s starter headgear (instead of the headgear equipped by the player).

      • Skitarii specific issue:

        • When personality scourging as Skitarii, all loadouts are unequipped AND all loadouts get a yellow exclamation mark, pointing to some error with the backpack slot.

        • Changing the equipped backpack resolves the issue.

    • Fixed!

  • The initial section of the Chasm Station HL-16-11 mission has some navigational issues that might cause enemies to navigate unpredictably.

That’s all for today!
We’ll see you on the Mourningstar.

– The Darktide Team
