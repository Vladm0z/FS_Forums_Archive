Hey Everyone,

Hotfix#84(1.10.3) is currently rolling out across our platforms. In the meantime, you can read the notes below.

This hotfix comes with some general bug fixes and solves some cosmetics clipping.

General Bug Fixes

  • Fixed an issue with explosion hit detection hitting players from further away than before.
  • Fixed an issue where players could find themselves unable to remove talent nodes when talents are in an invalid state.
  • Fixed an issue where Stim Supply will lock you in the animation where you can’t swap to melee or range.
  • Fixed majority of weapon and ability overheat/peril explosion not working.
  • Fixed performance issues related to the overheat/peril gain/loss in certain weapons.
  • Fixed an issue where the Boom Bringer missile was rendered outside of the model.
  • Fixed an issue where part of the stub pistols was floating around the player.
  • Fixed an issue with floating magazines when interrupting the reload by using the special attack on the stub pistols.
  • Fixed an issue that was limiting chat use on PS5.

Cosmetic Fixes

  • Fixed an issue where some backpack-type accessories would clip with the Ogryn “Baross Patrol Armour (XXXXL)” upper body cosmetic.
  • Fixed an issue where some backpack-type accessories would clip with the Psyker “Aureate Mk Vb Psykana Garb” upper body cosmetic.
  • Fixed an issue where some backpack-type accessories would clip with the Veteran “Magistratum Mk II Patrol Armour” upper body cosmetic.
  • Fixed an issue where the wrong blade ended up being used on the “Assassin’s Blade” cosmetic weapon skin. It is now short again, as intended.

Additional changes

  • Added some clearer information to the Stimm Lab info.
  • Changed dodge stats from the talent trees to also impact incoming ranged damage, instead of just melee damage*.

That’s all for today! This is most likely the last hotfix we’ll be doing this year as we slow down for the holidays. Stay tuned for an end of year post from us to talk about 2025 and what’s coming next for Darktide, very soon!

We’ll see you on the Mourningstar.

– The Darktide Team

Known Issue

* Experimental changes meant for mitigating the issue where dodge distance buffs negatively impacts time spent in dodging has resulted in unintended consequences that make dodging too effective. A fix is being investigated on both this and the original issue and will be delivered in the next hotfix.
