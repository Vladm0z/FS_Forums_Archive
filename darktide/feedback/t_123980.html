  1. Put it on backburner, don’t waste any more development hours on it beyond basic bugfixes and balancing tweaks; let it be a chill way for new players to farm some resources or whatever
  2. Repurpose the map generation engine it uses for the Adventure Mode, adapt it to using assets of the base game’s maps. Make it using the standard spawn algorithms of the base game, not the ones from Expeditions (which aren’t compatible with hoard shooter core idea)
  3. Enhance the algorithm so it would be capable of building rather complex map layouts using those standard assets as building bricks. May be train some AI model for that purpose
  4. Put 2-3 such missions with randomly generated maps to Missions Terminal in every difficulty, in each rotation (so they are either auto-regenerated every rotation, or you generate a dozen of them weekly, check them for issues quickly - and then they are used until the end of the week for that). Call them “Populace pacification missions” or whatever, the point is they won’t be “plot missions” anymore, no plot dialogues, nothing. On the loading screen you’ll hear generic canned phrases about you being sent into some district-without-name-to-remember to suppress unrest there and gather some clues on why it happened and who is behind it (represented by a new gatherable item, which could be used to exchange for some resources on the station, even)
  5. Add a new option to QP’s settings allowing players to exclude those missions from QP, if they dislike random generated maps

Should somewhat alleviate the issue of content shallowness, and help with serving oldtimers a gust of fresh air (as we can’t really hope FS will start adding new hand-crafted maps on regular basis; wasn’t like that in VT2, won’t be in DT either).

This is about 3.9 billion times more complicated then I think you think it is. Expeditions works because the maps are designed as tiles that can easily stick together, and there is no physical skybox. Most darktide maps are made around a theme and have you actually moving through a space with assets in the physical skybox adding most of the atmosphere. The way maps are structured would make it basically impossible to just turn them into tiles, you could make it so each airlock leads to a differently randomly selected place but that basically just means were playing the same 3 maps, just randomly selected parts of those 3 maps in a random order.

It would be possible to do this, they could design generic map blocks from each sector and then have a algorithm stick them together. This would work fine. But that is also basically the same amount of effort as just making multiple new maps in each sector. So I would rather they just put that effort into making like 3 more maps for each sector rather then a few dozen generic map blocks that a algorithm can stick together.
