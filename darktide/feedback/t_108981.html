I know some people don’t like to have those two actions combined, but I find this combo very convenient. There is a big issue though, due to Fatshark’s choice of how to implement it.

When you have only Dodge assigned to Space, you can hit it multiple times quickly (“spam” the action) - and it will result in dodges happening one after another (what you expect actually). When you have Jump also assigned to Space, when you do the same it will result in your character dodging, then jumping, then dodging, etc. You can only dodge repeatedly like this when you wait until previous dodge animation is fully completed - totally nonsensical behavior.

I’ve tried to play with settings in the Input submenu, but none of settings there resolve the issue. I think it either needs to be just changed, or may be one more setting added under Input submenu which will enable next behavior:

  • If enabled, a combination with direction key and Space key will be ALWAYS a Dodge, except for the case when forward direction key is used (alone, to still allow diagonal dodging) - then it will forward Jump.
