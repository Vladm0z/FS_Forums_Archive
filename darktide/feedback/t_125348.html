After doing some thorough testing with all the Devil’s Claw MK variants I’m not surprised that the weapon is so unpopular. I will leave my notes and suggestions about them.

MkVII:

This variant is currently the clear winner of the 3 in both horde clear and single target damage against armour. This is mostly due to it’s light combo attack speed that is way faster than the other two and the fact that it has actual good combos to use. However, what I would change is that the L3 attack chains into the H2 attack. That would make it possible to keep chaining strikedown attacks which is currently not possible with any of the 3 variants yet so desperately needed.

MkI:

This variant got it’s light combo pattern changed some time ago that L3 chains back to L2 instead of L1, meaning it has a more single target focused combo. Problem is, that the attack speed is inferior to the MkVII, which means it’s not worth it. I would change the light combo back to a normal 3 hit cycle, but with two single target attacks starting with L1 Strikedown > L2 Vanguard > L3 Stab. The pre-changed Mechanicus Power Sword showed that swords with a single target light combo can actually work well. The attack speed also needs to be as fast as the MkVII and it too should be possible to chain heavy and light strikedowns into each other.

MkIV:

This one is a total beginners trap. While it has a 4 hit light combo that only uses Vanguard attacks for horde, it’s damage against horde is actually the worst of all 3 variants. This is due to it’s vastly inferior attack speed with light attacks. Not only is it slower, it has this weird delay after L2 and L4 for no reason. Simply reduce the delay and set the attack speed on par with the MkVII. As for the H2 attack, I would change it to have both heavy attacks to be a strikedown. While it would be the simplest variant to use of all 3, it’s also the first one players have access to. The lack of light strikedown attacks is also a disadvantage that justifies 2 heavy strikedowns imo.

In summary, the MkI would be good at single target with light and horde with heavy attacks, the MkIV would be the opposite and the MkVII would have a mixed attack pattern that needs more use of switching between heavy and light, while all 3 would have the possibility to chain single target attacks into each other.

Note: none of these changes would need new animations, as there are already two heavy strikedown attacks from both shoulders and the push follow from the MkVII is a stab.
