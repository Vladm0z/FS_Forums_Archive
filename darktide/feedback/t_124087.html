Noospheric Command is so strong, that when several Skitarii use it liberally, it wipes pretty much everything but hordes.
Even when a single Skitarius uses it liberally it basically replaces that persons ranged weapon. I sometimes use it more than my melee attack, since there is no limit on it.

Some type of limit is sorely needed here.

My preferred idea would be a soft cooldown, where the longer you don’t use it, the more additional fire rate for the skull, meaning that when you spam it, it looses effectiveness. Although this version loses the burst potential of shooting and double-tagging at the same time.

The second idea I have would be to put it on a hard cooldown like an ability. This could be paired with charges, to keep the burst potential.

Another idea I’ve heard of would be to tie it to capacitance / ability charge, which I personally don’t like, since its a Blitz and would reduce build variety, since you couldn’t build for ability and Noospheric Command at the same time.

There might be other, better limits that could be used. This is just my five pennies.
We need a limit here.
