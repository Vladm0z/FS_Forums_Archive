I
Increto • 2026-09-30 19:46:08

Tapping “R” once to quell peril works perfectly fine in every other game mode. However, in Havoc (with the quell reduction modifier), a single tap no longer works. It forces you to hold the key to get the same result.

I understand the intent behind this change: spam-tapping “R” was an unintended exploit that bypassed the quell reduction. It needed to be fixed. However, this implementation has improved the game for no one.

This change negatively impacts:
• Veterans: Who rely on muscle memory built over hundreds of hours across all other game modes.
• New Players: Who spent ages learning the mechanics, only to have them suddenly stop working in end-game content, causing frustration and overloads.
• Teammates: Who suffer potential havoc progression loss from psykers overloading and derailing that game because of the change.

Havoc should be harder (toughness reduction, etc.), but making it harder by breaking fundamental, cross-mode game mechanics is just not fun.

A better solution: Keep the spam-tapping nerf (so spamming doesn’t outpace holding “R”), but please restore the functionality of the first single tap so it behaves exactly like it does in every other game mode.

I was incredibly excited for this update for weeks, but now my favorite game mode just feels frustrating. Please Fatshark, I just want to come home and have fun.
