So I had a similar experience to this recently and do you know what worked WONDERS?

Completely cleaning my Nvidia graphics shader cache (the proper way that requires multiple reboot etc) and then I switched the cache to unlimited in the nvidia control panel once done.

My game no longer stutters or rubberbands anywhere near the level it used to. It feels like a totally different game.

Worth a go IMO!!

If this fixes it for you, like it did for me, then really FS should be pinning a post about how everyone should do this.

It is crazy how better my performance is after cleaning shader cache. It felt like network issues the entire time but it seems it wasn’t the cause for me.
