Suggestion: Two Different Corruption Types

2 Posts • 50 Views

The main issue with curios that increase the maximum number of wounds is that it has the side-effect of reducing the potency of gradual cleansing effects (such as the Veteran’s Field Improvisation, the Zealot’s Beacon of Purity, and the Hive Scum’s Stimm Supply) by adding more “checkpoints” for corruption buildup, restricting the aforementioned effects to cleansing smaller portions of the health bar. This issue stems from downs and external buildup sources sharing the same corruption meter.

I think this could be rectified by adding a separate type of corruption with more lenient properties, and having all sources of external corruption buildup use this new type instead. For now, let’s refer to this new type as “green corruption”, and the existing type as “purple corruption”. Below is an edit I made of a screenshot (that I grabbed from the Discord server) to help make this concept easier to grasp.

image444×127 27 KB

For purple corruption:

  • One wound is filled with purple corruption each time the player goes down (like how it currently works).
  • If a whole wound is filled with purple corruption, it can only be cleansed using med stimms or a medicae station (again, like how it currently works).
  • When cleansing using a med stimm, the purple corruption would be removed first.

For green corruption:

  • Green corruption would come from all other sources (Pox Hounds, Poxbursters, Beasts of Nurgle, tox gas, blight puddles, etc.).
  • Green corruption could be cleansed by Field Improvisation, Beacon of Purity, and Stimm Supply regardless of the wound it’s on, thereby eliminating the detrimental side-effect of increasing the maximum number of wounds.
  • Med stimms would go on to remove green corruption if there is no purple corruption left to cleanse.

Both types of corruption would still work to limit the player’s maximum health and the amount they can heal using medi-packs without Field Improvisation. Death would occur if the player’s health reaches zero while the sum of green and purple corruption encroaches upon their last wound.
